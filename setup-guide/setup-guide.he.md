חבר את GateTap לבקר הגישה שלך

## לפני שמתחילים

ודא שהמכשיר שלך מחובר לאותה רשת מקומית כמו בקר הגישה. לדוגמה, ודא שה-iPhone מחובר ל-Wi-Fi הביתי ולא לחיבור נתונים סלולריים.

GateTap פועל כולו בתוך הרשת המקומית שלך וצריך:
• את כתובת ה-IP של הבקר
• שם משתמש וסיסמה


## שלב 1: מצא את כתובת ה-IP של בקר הגישה

כדי לחבר את GateTap, צריך את כתובת ה-IP של הבקר ואת פרטי ההתחברות - ראה שלב 2.

בחר אחת מהאפשרויות הבאות:


## אפשרות א׳: שאל את המתקין שלך (מומלץ)

אם המערכת הותקנה על ידי חשמלאי או טכנאי, סביר שהוא כבר הגדיר הכול.

במקרים רבים:
• הבקר משתמש בכתובת IP קבועה
• או שהנתב מקצה לו את אותה IP באמצעות שמירת DHCP

בקש ממנו את כתובת ה-IP ואת פרטי ההתחברות. בדרך כלל זו הדרך הקלה והמהירה ביותר.


## אפשרות ב׳: בדוק את הנתב שלך

פתח את דף התצורה של הנתב וחפש מכשירים מחוברים.

כדי לגשת לנתב, בדרך כלל צריך את הכתובת המקומית שלו, למשל `192.168.1.1` או שם כמו `fritz.box`, ואת פרטי ההתחברות של הנתב.

החלק הזה עשוי להיקרא:
• רשת
• מכשירים מחוברים
• LAN
• לקוחות DHCP

חפש:
• מכשירים קוויים לא מוכרים
• רשומות שעשויות לייצג את הבקר שלך

כתובת ה-IP בדרך כלל תיראה כך:
`192.168.x.x` או `10.0.x.x`

![דוגמה למכשירים מחוברים בנתב](../assets/setup-guide/he/img_01_en_US.png)


## אפשרות ג׳: סרוק את הרשת שלך

השתמש באפליקציית סריקת רשת במכשיר שלך.

סרוק את הרשת ונסה לפתוח כתובות IP שנמצאו ב-Safari, לדוגמה:

`http://192.168.1.50`

אם מופיע דף ההתחברות של בקר הגישה, מצאת את הכתובת הנכונה.

![דוגמה לאפליקציית סריקת רשת](../assets/setup-guide/he/img_02_en_US.png)


## שלב 2: מצא את פרטי ההתחברות של בקר הגישה

חלק מהבקרים עדיין משתמשים בפרטי התחברות ברירת מחדל. דוגמה נפוצה היא שם המשתמש `abc` עם הסיסמה `654321`.

שמות משתמש נפוצים נוספים מהמפעל הם `user`, `admin` או `123`. אפשר לנסות אותם עם סיסמאות טיפוסיות כמו `1234`, `user` או `password`, או וריאציה שלהן.

אם המערכת הותקנה באופן מקצועי, שאל את המתקין אם פרטי ברירת המחדל שונו.


## שלב 3: הוסף את בקר הגישה ב-GateTap

פתח את GateTap והזן:
• כתובת IP
• שם משתמש
• סיסמה

השתמש באותם פרטי התחברות כמו בממשק האינטרנט של בקר הגישה.


## שלב 4: בדוק את החיבור

שמור את התצורה ונסה לפתוח דלת או שער.

אם שום דבר לא קורה, בדוק:
• שהמכשיר שלך נמצא באותה רשת כמו בקר הגישה
• שכתובת ה-IP נכונה
• שבקר הגישה מחובר לחשמל ונגיש


## שלב 5: שמור על כתובת IP יציבה

כדי להימנע מבעיות בהמשך, הבקר צריך להשתמש תמיד באותה כתובת IP.

אפשר לעשות זאת באמצעות:
• הגדרת IP סטטי בבקר
• יצירת שמירת DHCP בנתב


## מצב הדגמה

GateTap כולל גם מצב הדגמה. אפשר להפעיל שרת אינטרנט מקומי להדגמה מתוך האפליקציה ואז להוסיף אותו כמו בקר רגיל.

כך יש לך נתיב בדיקה ידוע שעובד כדי לוודא ש-GateTap עצמו פועל כראוי, גם אם אין לך כרגע גישה לבקר גישה פיזי.


## אבטחה

הנתונים שלך נשארים במכשיר שלך.

באפשרותך להגן על GateTap באמצעות Face ID או Touch ID בהגדרות האפליקציה.
