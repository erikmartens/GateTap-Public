เชื่อมต่อ GateTap กับตัวควบคุมการเข้าถึงของคุณ

## ก่อนที่คุณจะเริ่ม

ตรวจสอบให้แน่ใจว่าอุปกรณ์ของคุณเชื่อมต่อกับเครือข่ายท้องถิ่นเดียวกับตัวควบคุมการเข้าถึงของคุณ เช่น ตรวจสอบว่า iPhone อยู่บน Wi-Fi ที่บ้าน ไม่ใช่การเชื่อมต่อข้อมูลมือถือ

GateTap ทำงานทั้งหมดภายในเครือข่ายท้องถิ่นของคุณและต้องใช้:

- ที่อยู่ IP ของตัวควบคุม
- ชื่อผู้ใช้และรหัสผ่าน


## ขั้นตอนที่ 1: ค้นหาที่อยู่ IP ของตัวควบคุมการเข้าถึง

ในการเชื่อมต่อ GateTap คุณต้องใช้ที่อยู่ IP ของตัวควบคุมและข้อมูลเข้าสู่ระบบ - ดูขั้นตอนที่ 2

เลือกหนึ่งในตัวเลือกต่อไปนี้:


## ตัวเลือก A: สอบถามผู้ติดตั้งของคุณ (แนะนำ)

หากระบบของคุณติดตั้งโดยช่างไฟฟ้าหรือช่างเทคนิค พวกเขาอาจกำหนดค่าทุกอย่างไว้แล้ว

ในหลายกรณี:

- ตัวควบคุมใช้ที่อยู่ IP แบบคงที่
- หรือเราเตอร์กำหนด IP เดิมให้ผ่านการจอง DHCP

ขอที่อยู่ IP และข้อมูลเข้าสู่ระบบจากพวกเขา โดยปกติจะเป็นวิธีที่ง่ายและเร็วที่สุด


## ตัวเลือก B: ตรวจสอบเราเตอร์ของคุณ

เปิดหน้าการกำหนดค่าของเราเตอร์และค้นหาอุปกรณ์ที่เชื่อมต่ออยู่

ในการเข้าถึงเราเตอร์ โดยปกติคุณต้องใช้ที่อยู่ภายใน เช่น `192.168.1.1` หรือชื่ออย่าง `fritz.box` และข้อมูลเข้าสู่ระบบของเราเตอร์

ส่วนนี้อาจเรียกว่า:

- เครือข่าย
- อุปกรณ์ที่เชื่อมต่อ
- LAN
- ไคลเอนต์ DHCP

มองหา:

- อุปกรณ์แบบมีสายที่ไม่รู้จัก
- รายการที่อาจเป็นตัวควบคุมของคุณ

ที่อยู่ IP โดยทั่วไปจะมีลักษณะดังนี้:
`192.168.x.x` หรือ `10.0.x.x`

![ตัวอย่างอุปกรณ์ที่เชื่อมต่อในเราเตอร์](../assets/setup-guide/th/img_01_en_US.png)


## ตัวเลือก C: สแกนเครือข่ายของคุณ

ใช้แอปสแกนเครือข่ายบนอุปกรณ์ของคุณ

สแกนเครือข่ายของคุณและลองเปิดที่อยู่ IP ที่พบใน Safari เช่น:

`http://192.168.1.50`

หากหน้าล็อกอินของตัวควบคุมการเข้าถึงปรากฏขึ้น แสดงว่าคุณพบที่อยู่ที่ถูกต้องแล้ว

![ตัวอย่างแอปสแกนเครือข่าย](../assets/setup-guide/th/img_02_en_US.png)


## ขั้นตอนที่ 2: ค้นหาข้อมูลเข้าสู่ระบบของตัวควบคุมการเข้าถึง

ตัวควบคุมบางรุ่นยังใช้ข้อมูลเข้าสู่ระบบเริ่มต้นอยู่ ตัวอย่างที่พบบ่อยคือชื่อผู้ใช้ `abc` พร้อมรหัสผ่าน `654321`

ชื่อผู้ใช้จากโรงงานที่ใช้กันทั่วไปอื่น ๆ ได้แก่ `user`, `admin` หรือ `123` คุณสามารถลองใช้ร่วมกับรหัสผ่านทั่วไป เช่น `1234`, `user` หรือ `password` หรือรูปแบบใกล้เคียง

หากระบบของคุณติดตั้งโดยผู้เชี่ยวชาญ ให้ถามผู้ติดตั้งว่ามีการเปลี่ยนข้อมูลเข้าสู่ระบบเริ่มต้นหรือไม่


## ขั้นตอนที่ 3: เพิ่มตัวควบคุมการเข้าถึงใน GateTap

เปิด GateTap แล้วป้อน:

- ที่อยู่ IP
- ชื่อผู้ใช้ของคุณ
- รหัสผ่านของคุณ

ใช้ข้อมูลเข้าสู่ระบบเดียวกับเว็บอินเทอร์เฟซของตัวควบคุมการเข้าถึง


## ขั้นตอนที่ 4: ทดสอบการเชื่อมต่อ

บันทึกการกำหนดค่าแล้วลองเปิดประตูหรือประตูรั้ว

หากไม่มีอะไรเกิดขึ้น ให้ตรวจสอบ:

- อุปกรณ์ของคุณอยู่ในเครือข่ายเดียวกับตัวควบคุมการเข้าถึง
- ที่อยู่ IP ถูกต้อง
- ตัวควบคุมการเข้าถึงเปิดอยู่และเข้าถึงได้


## ขั้นตอนที่ 5: รักษาที่อยู่ IP ให้คงที่

เพื่อหลีกเลี่ยงปัญหาในภายหลัง ตัวควบคุมควรใช้ที่อยู่ IP เดิมเสมอ

ทำได้โดย:

- ตั้งค่า IP แบบคงที่บนตัวควบคุม
- สร้างการจอง DHCP ในเราเตอร์


## โหมดสาธิต

GateTap ยังมีโหมดสาธิตด้วย คุณสามารถเริ่มเว็บเซิร์ฟเวอร์สาธิตภายในเครื่องจากในแอป แล้วเพิ่มได้เหมือนตัวควบคุมปกติ

วิธีนี้ให้เส้นทางทดสอบที่ทราบว่าใช้งานได้ เพื่อยืนยันว่า GateTap ทำงานถูกต้อง แม้ว่าตอนนี้คุณจะไม่มีตัวควบคุมการเข้าถึงจริงให้ใช้งานก็ตาม


## ความปลอดภัย

ข้อมูลของคุณยังคงอยู่ในอุปกรณ์ของคุณ

คุณสามารถเลือกป้องกัน GateTap โดยใช้ Face ID หรือ Touch ID ในการตั้งค่าแอพได้
