Συνδέστε το GateTap στον ελεγκτή πρόσβασης

## Πριν ξεκινήσετε

Βεβαιωθείτε ότι το iPhone σας είναι συνδεδεμένο στο ίδιο τοπικό δίκτυο με τον ελεγκτή πρόσβασης.

Το GateTap λειτουργεί εξ ολοκλήρου στο τοπικό σας δίκτυο και χρειάζεται:
• Η διεύθυνση IP του ελεγκτή
• Όνομα χρήστη και κωδικό πρόσβασης


## Βήμα 1: Βρείτε τη διεύθυνση και τα διαπιστευτήρια του ελεγκτή

Για να συνδέσετε το GateTap, χρειάζεστε τη διεύθυνση IP του ελεγκτή και τα διαπιστευτήρια σύνδεσης.

Επιλέξτε μία από τις παρακάτω επιλογές:


## Επιλογή Α: Ρωτήστε τον εγκαταστάτη σας (συνιστάται)

Εάν το σύστημά σας εγκαταστάθηκε από ηλεκτρολόγο ή τεχνικό, πιθανότατα έχουν ήδη διαμορφώσει τα πάντα.

Σε πολλές περιπτώσεις:
• Ο ελεγκτής χρησιμοποιεί μια σταθερή διεύθυνση IP
• Ή ο δρομολογητής εκχωρεί την ίδια IP μέσω κράτησης

Ρωτήστε τους τη διεύθυνση IP και τα στοιχεία σύνδεσης. Αυτός είναι συνήθως ο πιο εύκολος και γρήγορος τρόπος.


## Επιλογή Β: Ελέγξτε τον δρομολογητή σας

Ανοίξτε τη σελίδα διαμόρφωσης του δρομολογητή σας και αναζητήστε συνδεδεμένες συσκευές.

Για να αποκτήσετε πρόσβαση στο δρομολογητή σας, χρειάζεστε συνήθως την τοπική του διεύθυνση (π.χ. `192.168.1.1` ή ένα όνομα όπως `fritz.box`) και τα διαπιστευτήρια σύνδεσης του δρομολογητή.

Αυτή η ενότητα μπορεί να ονομάζεται:
• Συνδεδεμένες συσκευές
• LAN
• Πελάτες DHCP

Αναζητήστε:
• Άγνωστες ενσύρματες συσκευές
• Εγγραφές που μπορεί να αντιπροσωπεύουν τον ελεγκτή σας

Η διεύθυνση IP συνήθως μοιάζει με:
`192.168.x.x` ή `10.0.x.x`.

![Παράδειγμα συσκευών συνδεδεμένων με δρομολογητή](../assets/setup-guide/el/img_01.png)


## Επιλογή Γ: Σάρωση του δικτύου σας

Χρησιμοποιήστε μια εφαρμογή σαρωτή δικτύου στο iPhone ή τον υπολογιστή σας.

Σαρώστε το δίκτυό σας και δοκιμάστε να ανοίξετε τις ανακαλυφθείσες διευθύνσεις IP στο Safari, για παράδειγμα:

`http://192.168.1.50`

Εάν εμφανιστεί η σελίδα σύνδεσης του ελεγκτή, έχετε βρει τη σωστή διεύθυνση.

![Παράδειγμα σαρωτή δικτύου](../assets/setup-guide/el/img_02.png)


## Βήμα 2: Προσθέστε τον ελεγκτή στο GateTap

Ανοίξτε το GateTap και εισάγετε:
• Η διεύθυνση IP
• Το όνομα χρήστη σας
• Ο κωδικός πρόσβασής σας

Χρησιμοποιήστε τα ίδια διαπιστευτήρια όπως και για τη διεπαφή ιστού του ελεγκτή.


## Βήμα 3: Δοκιμάστε τη σύνδεση

Αποθηκεύστε τη διαμόρφωσή σας και δοκιμάστε να ανοίξετε μια πόρτα ή μια πύλη.

Εάν δεν συμβεί τίποτα, ελέγξτε:
• Το iPhone σας βρίσκεται στο ίδιο δίκτυο
• Η διεύθυνση IP είναι σωστή
• Ο ελεγκτής είναι τροφοδοτημένος και προσβάσιμος


## Βήμα 4: Διατηρήστε τη διεύθυνση IP σταθερή

Για να αποφύγετε προβλήματα αργότερα, ο ελεγκτής θα πρέπει πάντα να χρησιμοποιεί την ίδια διεύθυνση IP.

Αυτό μπορεί να γίνει με:
• Ρύθμιση στατικής IP στον ελεγκτή
• Δημιουργία κράτησης DHCP στο δρομολογητή σας


## Ασφάλεια

Τα δεδομένα σας παραμένουν στη συσκευή σας.

Μπορείτε προαιρετικά να προστατεύσετε το GateTap χρησιμοποιώντας το Face ID ή το Touch ID στις ρυθμίσεις της εφαρμογής.
