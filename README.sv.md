_**Omedelbar kontroll av dörrar och grindar**_

GateTap låter dig styra kompatibla lokala åtkomstkontroller från din iPhone när du är i ditt eget nätverk.

Appen ansluter direkt till kontrollern. Inget molnkonto krävs för kommandon.

---

## Funktioner

- Öppna dörrar och grindar från fliken Åtkomst.
- Spara kontrollerns adress och eventuellt inloggningsuppgifter lokalt.
- Använd tillfälliga uppgifter för den aktuella appsessionen.
- Skydda appen med Face ID, Touch ID eller enhetskod.
- Läs installation, integritet och villkor från samma källa som appen.
