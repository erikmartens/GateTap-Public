_**די למאבק בממשקי אינטרנט מיושנים.**_

מערכות בקרת גישה רבות מסתמכות על דפי דפדפן איטיים וקשים לשימוש רק כדי לפתוח דלת או שער. GateTap נותנת לך דרך מהירה, מודרנית ונוחה למגע לשלוט במערכת ישירות מה-iPhone.

GateTap נבנתה לרשתות מקומיות ומתחברת ישירות לבקר הגישה שלך — בלי ענן, בלי חשבונות ובלי עיכובים.

---

## תכונות

• שליטה בדלתות ובשערים בלחיצה אחת  
• התחברות מהירה עם פרטי גישה שמורים (אופציונלי)  
• 🔐 הגנה אופציונלית באמצעות Face ID / Touch ID  
• פועלת כולה בתוך הרשת המקומית שלך  
• ממשק נקי ומותאם למגע  
• לא נדרש חיבור לענן  

---

## הגדרה

GateTap מיועדת למשתמשים מתקדמים ודורשת הגדרה ידנית:

1. הזן את כתובת ה-IP המקומית של המכשיר  
2. ספק את פרטי ההתחברות שלך  
3. בדוק את החיבור והתחל לשלוט במערכת  

GateTap עובדת עם מערכות שמספקות ממשק אינטרנט מובנה. התאימות תלויה בתצורת החומרה שלך.

קרא את [מדריך ההגדרה](../setup-guide/setup-guide.he.md) המלא.

## פרטיות לפני הכול

הנתונים שלך נשארים במכשיר שלך. GateTap לא שולחת פרטי התחברות או פקודות לשרתים חיצוניים.

ניתן לכבות בכל עת דיווח קריסות אופציונלי.

קרא את [מדיניות הפרטיות](../legal/he/privacy-policy.he.md) ואת [תנאי השימוש](../legal/he/terms-of-use.he.md) המלאים.
