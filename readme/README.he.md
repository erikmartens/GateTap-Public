_**ממשק iPhone מודרני למערכות בקרת גישה תואמות המנוהלות דרך האינטרנט.**_

בקר גישה הוא מכשיר שמנהל אלקטרונית את פתיחתם של דלתות, שערים, מוסכים או מחסומים — למשל על ידי הפעלת זמזם דלת דרך מערכת האינטרקום שלך או שליטה במנוע שער.

מערכות בקרת גישה מודרניות רבות מחוברות לרשת המקומית וניתן לשלוט בהן דרך ממשק אינטרנט. עם זאת, הממשקים האלה לעיתים קרובות איטיים, קשים ומסורבלים לשימוש. GateTap מחליפה דפי אינטרנט מיושנים בחוויה מהירה, מותאמת למגע ומיועדת ל‑iPhone.

GateTap נבנתה עבור רשתות מקומיות ומתחברת ישירות לבקרי גישה תואמים — ללא שירותי ענן, מנויים או חשבונות חיצוניים.

## תכונות

• ☑️ שליטה מודרנית בשערים ובדלתות  
• 📱 ממשק אינטואיטיבי ומותאם למגע  
• ⚡ כניסה מהירה עם פרטי התחברות שמורים באופן מאובטח או פרטי התחברות זמניים להפעלה  
• 🔐 הגנה אופציונלית לאפליקציה באמצעות Face ID / Touch ID  
• 📡 תקשורת ישירה ברשת המקומית  
• ☁️ אין צורך בחיבור לענן  
• 🖥️ מיועדת לבקרים מובנים המנוהלים דרך ממשק אינטרנט  
• 🏢 תמיכה במספר בקרים / מספר אתרים

## תאימות

GateTap מיועדת לבקרי גישה מסוימים עם Ethernet או Wi‑Fi המספקים ממשק ניהול מובנה מבוסס דפדפן.

מערכות תואמות מספקות בדרך כלל:
- גישה מקומית מבוססת IP
- דפי ניהול אינטרנט מובנים
- פונקציית כניסה בדפדפן
- שליטה בממסר או בבקרת גישה דרך ממשק האינטרנט

התאימות תלויה ב:
- דגם הבקר
- גרסת הקושחה
- מבנה ממשק האינטרנט
- תצורת הרשת

### לא תואמת ל

GateTap בדרך כלל **אינה תואמת** ל:
- מערכות ענן בלבד
- מערכות Bluetooth בלבד
- שלטי IR עצמאיים
- בקרי גישה ללא ממשקי אינטרנט
- קוראים כלליים ללא מודולי רשת

[ראה את הרשימה הידועה של מכשירים תואמים.](../support/he/compatibility.he.md)

## נסו לפני הרכישה

ניתן להוריד ולהגדיר את GateTap בחינם כדי לבדוק תאימות למערכת שלך לפני הרכישה.

הגרסה החינמית מאפשרת לך:
- להתחבר לבקר שלך
- לאמת פרטי התחברות
- לבדוק תאימות
- להציג תצוגה מקדימה של ממשק הבקר

רכישה חד-פעמית בתוך האפליקציה פותחת:
- הפעלת שערים ודלתות
- שימוש תפעולי מלא בבקר
- תמיכה במספר בקרים / מספר אתרים
- תכונות מתקדמות עתידיות

אין צורך במנוי.

## הגדרה

GateTap מיועדת למשתמשים בעלי ניסיון טכני ודורשת הגדרה ידנית.

1. הזן את כתובת ה‑IP המקומית של הבקר  
2. ספק את פרטי ההתחברות שלך  
3. בדוק את החיבור  
4. פתח את מלוא הפונקציונליות והתחל לשלוט במערכת שלך ישירות מה‑iPhone  

קרא את [מדריך ההגדרה](../setup-guide/setup-guide.he.md) המלא.

## תמיכה וסיוע בתאימות

מכיוון שחומרת בקרת גישה משתנה משמעותית בין יצרנים וגרסאות קושחה, לא ניתן להבטיח תאימות לכל המערכות.

אם הבקר שלך אינו נתמך כרגע, ייתכן שעדיין ניתן יהיה להוסיף תמיכה.

משתמשים יכולים לפנות לתמיכה ולספק:
- צילומי מסך של ממשק האינטרנט של הבקר
- דפי HTML מיוצאים
- מידע על דגם הבקר
- פרטי קושחה

כאשר הדבר אפשרי, ניתן לפתח ולבדוק שיפורי תאימות יחד עם משתמשים באמצעות גרסאות בטא של TestFlight.

שים לב שתהליך זה יכול להיות טכני ועשוי לדרוש שיתוף פעולה פעיל במהלך הבדיקות.
