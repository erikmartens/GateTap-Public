_**Μια σύγχρονη διεπαφή iPhone για συμβατά συστήματα ελέγχου πρόσβασης που διαχειρίζονται μέσω web.**_

Ένας ελεγκτής πρόσβασης είναι μια συσκευή που διαχειρίζεται ηλεκτρονικά το άνοιγμα θυρών, πυλών, γκαράζ ή μπαρών — για παράδειγμα ενεργοποιώντας το κουδούνι πόρτας μέσω του συστήματος ενδοεπικοινωνίας ή ελέγχοντας έναν κινητήρα πύλης.

Πολλά σύγχρονα συστήματα ελέγχου πρόσβασης είναι συνδεδεμένα στο τοπικό δίκτυο και μπορούν να ελεγχθούν μέσω μιας διεπαφής web. Ωστόσο, αυτές οι διεπαφές είναι συχνά αργές, δύσκολες και δυσκίνητες στη χρήση. Το GateTap αντικαθιστά παλιές ιστοσελίδες με μια γρήγορη εμπειρία βελτιστοποιημένη για αφή και σχεδιασμένη για iPhone.

Σχεδιασμένο για τοπικά δίκτυα, το GateTap συνδέεται απευθείας με συμβατούς ελεγκτές πρόσβασης — χωρίς υπηρεσίες cloud, συνδρομές ή εξωτερικούς λογαριασμούς.

## Λειτουργίες

• ☑️ Σύγχρονος έλεγχος πυλών και θυρών  
• 📱 Διαισθητική διεπαφή βελτιστοποιημένη για αφή  
• ⚡ Γρήγορη σύνδεση με ασφαλώς αποθηκευμένα διαπιστευτήρια ή προσωρινά διαπιστευτήρια συνεδρίας  
• 🔐 Προαιρετική προστασία της εφαρμογής με Face ID / Touch ID  
• 📡 Άμεση επικοινωνία στο τοπικό δίκτυο  
• ☁️ Δεν απαιτείται σύνδεση στο cloud  
• 🖥️ Σχεδιασμένο για ενσωματωμένους ελεγκτές που διαχειρίζονται μέσω web  
• 🏢 Υποστήριξη πολλών ελεγκτών / πολλών χώρων

## Συμβατότητα

Το GateTap έχει σχεδιαστεί για συγκεκριμένους ελεγκτές πρόσβασης με Ethernet ή Wi‑Fi που παρέχουν ενσωματωμένη διεπαφή διαχείρισης μέσω προγράμματος περιήγησης.

Τα συμβατά συστήματα συνήθως παρέχουν:
- τοπική πρόσβαση μέσω IP
- ενσωματωμένες σελίδες διαχείρισης web
- λειτουργία σύνδεσης μέσω προγράμματος περιήγησης
- έλεγχο ρελέ ή πρόσβασης μέσω της διεπαφής web

Η συμβατότητα εξαρτάται από:
- το μοντέλο του ελεγκτή
- την έκδοση firmware
- τη δομή της διεπαφής web
- τη διαμόρφωση δικτύου

### Δεν είναι συμβατό με

Το GateTap γενικά **δεν είναι συμβατό** με:
- συστήματα μόνο cloud
- συστήματα μόνο Bluetooth
- αυτόνομα τηλεχειριστήρια IR
- ελεγκτές πρόσβασης χωρίς διεπαφές web
- γενικούς αναγνώστες χωρίς μονάδες δικτύου

[Δείτε τη γνωστή λίστα συμβατών συσκευών.](../support/el/compatibility.el.md)

## Δοκιμή πριν από την αγορά

Το GateTap μπορεί να ληφθεί και να διαμορφωθεί δωρεάν, ώστε να επαληθεύσετε τη συμβατότητα με το σύστημά σας πριν από την αγορά.

Η δωρεάν έκδοση σάς επιτρέπει να:
- συνδεθείτε στον ελεγκτή σας
- επαληθεύσετε τα διαπιστευτήρια σύνδεσης
- δοκιμάσετε τη συμβατότητα
- δείτε προεπισκόπηση της διεπαφής του ελεγκτή

Μια εφάπαξ αγορά εντός εφαρμογής ξεκλειδώνει:
- ενεργοποίηση πυλών και θυρών
- πλήρη λειτουργική χρήση του ελεγκτή
- υποστήριξη πολλών ελεγκτών / πολλών χώρων
- μελλοντικές προηγμένες λειτουργίες

Δεν απαιτείται συνδρομή.

## Ρύθμιση

Το GateTap προορίζεται για τεχνικά έμπειρους χρήστες και απαιτεί χειροκίνητη διαμόρφωση.

1. Εισαγάγετε την τοπική διεύθυνση IP του ελεγκτή σας  
2. Παρέχετε τα διαπιστευτήρια σύνδεσης  
3. Δοκιμάστε τη σύνδεση  
4. Ξεκλειδώστε την πλήρη λειτουργικότητα και αρχίστε να ελέγχετε το σύστημά σας απευθείας από το iPhone  

Διαβάστε τον πλήρη [Οδηγό ρύθμισης](../setup-guide/setup-guide.el.md).

## Υποστήριξη και βοήθεια συμβατότητας

Επειδή το υλικό ελέγχου πρόσβασης διαφέρει σημαντικά μεταξύ κατασκευαστών και εκδόσεων firmware, η συμβατότητα δεν μπορεί να εγγυηθεί για όλα τα συστήματα.

Αν ο ελεγκτής σας δεν υποστηρίζεται προς το παρόν, η υποστήριξη μπορεί ακόμη να είναι δυνατή.

Οι χρήστες μπορούν να επικοινωνήσουν με την υποστήριξη και να παρέχουν:
- στιγμιότυπα οθόνης της διεπαφής web του ελεγκτή
- εξαγόμενες σελίδες HTML
- πληροφορίες μοντέλου ελεγκτή
- λεπτομέρειες firmware

Όταν είναι εφικτό, μπορούν να αναπτυχθούν και να δοκιμαστούν βελτιώσεις συμβατότητας μαζί με τους χρήστες μέσω beta εκδόσεων TestFlight.

Λάβετε υπόψη ότι αυτή η διαδικασία μπορεί να είναι τεχνική και ενδέχεται να απαιτεί ενεργή συνεργασία κατά τη διάρκεια των δοκιμών.
