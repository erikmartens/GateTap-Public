_**Τέλος στις παλιές και δύσχρηστες διεπαφές web.**_

Πολλά συστήματα ελέγχου πρόσβασης βασίζονται σε αργές και δύσχρηστες σελίδες προγράμματος περιήγησης μόνο για να ανοίξουν μια πόρτα ή πύλη. Το GateTap σού δίνει έναν γρήγορο, σύγχρονο και φιλικό στην αφή τρόπο ελέγχου απευθείας από το iPhone.

Σχεδιασμένο για τοπικά δίκτυα, το GateTap συνδέεται απευθείας με τον ελεγκτή πρόσβασης — χωρίς cloud, χωρίς λογαριασμούς, χωρίς καθυστερήσεις.

---

## Δυνατότητες

• Έλεγχος πόρτας και πύλης με ένα άγγιγμα  
• Γρήγορη σύνδεση με αποθηκευμένα διαπιστευτήρια (προαιρετικά)  
• 🔐 Προαιρετική προστασία με Face ID / Touch ID  
• Λειτουργεί αποκλειστικά στο τοπικό σας δίκτυο  
• Καθαρό περιβάλλον βελτιστοποιημένο για αφή  
• Δεν απαιτείται σύνδεση στο cloud  

---

## Ρύθμιση

Το GateTap απευθύνεται σε προχωρημένους χρήστες και απαιτεί χειροκίνητη ρύθμιση:

1. Πληκτρολογήστε την τοπική διεύθυνση IP της συσκευής  
2. Καταχωρίστε τα στοιχεία σύνδεσης  
3. Δοκιμάστε τη σύνδεση και αρχίστε να ελέγχετε το σύστημα  

Το GateTap λειτουργεί με συστήματα που διαθέτουν ενσωματωμένη διεπαφή web. Η συμβατότητα εξαρτάται από τη διαμόρφωση του υλικού σας.

Διαβάστε τον πλήρη [Οδηγό ρύθμισης](../setup-guide/setup-guide.el.md).

## Πρώτα η ιδιωτικότητα

Τα δεδομένα σας παραμένουν στη συσκευή σας. Το GateTap δεν στέλνει διαπιστευτήρια ή εντολές σε εξωτερικούς διακομιστές.

Η προαιρετική αναφορά σφαλμάτων μπορεί να απενεργοποιηθεί οποιαδήποτε στιγμή.
