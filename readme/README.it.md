_**Basta lottare con interfacce web obsolete.**_

Molti sistemi di controllo accessi si affidano a pagine browser lente e scomode solo per aprire una porta o un cancello. GateTap offre un modo rapido, moderno e ottimizzato per il touch per controllare il sistema direttamente dall’iPhone.

Pensato per le reti locali, GateTap si collega direttamente al tuo controller di accesso — niente cloud, niente account, niente ritardi.

---

## Funzioni

• Controllo di porte e cancelli con un tocco  
• Accesso rapido con credenziali salvate (opzionale)  
• 🔐 Protezione opzionale con Face ID / Touch ID  
• Funziona interamente nella rete locale  
• Interfaccia pulita e ottimizzata per il touch  
• Nessuna connessione cloud richiesta  

---

## Configurazione

GateTap è pensato per utenti esperti e richiede una configurazione manuale:

1. Inserisci l’indirizzo IP locale del dispositivo  
2. Fornisci le credenziali di accesso  
3. Testa la connessione e inizia a controllare il sistema  

GateTap funziona con sistemi che espongono un’interfaccia web integrata. La compatibilità dipende dalla configurazione dell’hardware.

Leggi la [Guida alla configurazione](../setup-guide/setup-guide.it.md) completa.

## Prima la privacy

I tuoi dati restano sul dispositivo. GateTap non invia credenziali o comandi a server esterni.

La segnalazione opzionale dei crash può essere disattivata in qualsiasi momento.
