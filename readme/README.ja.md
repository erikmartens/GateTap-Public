_**互換性のあるWeb管理型アクセス制御システム向けの、モダンなiPhoneインターフェイス。**_

アクセスコントローラとは、ドア、ゲート、ガレージ、バリアの開閉を電子的に管理する機器です。たとえば、インターホンシステム経由でドアブザーを作動させたり、ゲートモーターを制御したりします。

多くの最新のアクセス制御システムはローカルネットワークに接続され、Webインターフェイスから操作できます。しかし、こうしたインターフェイスは遅く、扱いにくく、操作が煩雑なことがよくあります。GateTapは、古いWebページを、iPhone向けに設計された高速でタッチ操作に最適化された体験に置き換えます。

GateTapはローカルネットワーク向けに構築されており、互換性のあるアクセスコントローラに直接接続します。クラウドサービス、サブスクリプション、外部アカウントは不要です。

## 機能

• ☑️ モダンなゲート・ドア操作  
• 📱 直感的でタッチ操作に最適化されたインターフェイス  
• ⚡ 安全に保存された認証情報、または一時的なセッション認証情報による高速ログイン  
• 🔐 Face ID / Touch IDによるアプリの任意保護  
• 📡 ローカルネットワークでの直接通信  
• ☁️ クラウド接続は不要  
• 🖥️ 組み込みWeb管理型コントローラ向けに設計  
• 🏢 複数コントローラ / 複数拠点をサポート

## 互換性

GateTapは、ブラウザベースの管理インターフェイスを内蔵する、特定のEthernetまたはWi‑Fi対応アクセスコントローラ向けに設計されています。

互換性のあるシステムは通常、次を提供します:
- ローカルIPベースのアクセス
- 内蔵Web管理ページ
- ブラウザログイン機能
- Webインターフェイス経由のリレーまたはアクセス制御

互換性は次によって異なります:
- コントローラのモデル
- ファームウェアバージョン
- Webインターフェイスの構造
- ネットワーク設定

### 互換性がないもの

GateTapは一般的に、次とは**互換性がありません**:
- クラウド専用システム
- Bluetooth専用システム
- 単体のIRリモコン
- Webインターフェイスを持たないアクセスコントローラ
- ネットワークモジュールのない汎用リーダー

[互換性のあるデバイスの既知リストを見る。](../support/ja/compatibility.ja.md)

## 購入前にお試しください

GateTapは無料でダウンロードして設定できるため、購入前にお使いのシステムとの互換性を確認できます。

無料版では次が可能です:
- コントローラに接続する
- ログイン認証情報を確認する
- 互換性をテストする
- コントローラインターフェイスをプレビューする

1回限りのアプリ内購入で次がアンロックされます:
- ゲートとドアの作動
- コントローラの完全な運用利用
- 複数コントローラ / 複数拠点のサポート
- 将来の高度な機能

サブスクリプションは不要です。

## 設定

GateTapは技術に詳しいユーザー向けで、手動設定が必要です。

1. コントローラのローカルIPアドレスを入力します  
2. ログイン認証情報を入力します  
3. 接続をテストします  
4. すべての機能をアンロックし、iPhoneから直接システムの操作を開始します  

完全な[設定ガイド](../setup-guide/setup-guide.ja.md)を読む。

## サポートと互換性の支援

アクセス制御ハードウェアはメーカーやファームウェアバージョンによって大きく異なるため、すべてのシステムでの互換性は保証できません。

現在お使いのコントローラがサポートされていない場合でも、対応できる可能性があります。

ユーザーはサポートに連絡し、次を提供できます:
- コントローラのWebインターフェイスのスクリーンショット
- エクスポートしたHTMLページ
- コントローラのモデル情報
- ファームウェアの詳細

実現可能な場合、互換性の改善はTestFlightベータビルドを通じてユーザーと共同で開発・テストできます。

このプロセスは技術的であり、テスト中に積極的な協力が必要になる場合があります。

## プライバシー優先

データはデバイス内に保存されます。

GateTapは次を外部サーバーへ送信しません:
- 認証情報
- コマンド
- コントローラーデータ

任意のクラッシュレポートはいつでも無効にできます。

完全な[プライバシーポリシー](../legal/ja/privacy-policy.ja.md)と[利用規約](../legal/ja/terms-of-use.ja.md)を読む。
