_**古いWebインターフェイスに悩まされるのは終わりです。**_

多くのアクセス制御システムでは、ドアやゲートを開けるだけのために、遅くて使いにくいブラウザページを使う必要があります。GateTapなら、iPhoneから直接、すばやくモダンでタッチ操作に適した方法でシステムを操作できます。

GateTapはローカルネットワーク向けに設計されており、アクセスコントローラに直接接続します。クラウドもアカウントも待ち時間も不要です。

---

## 機能

• ワンタップでドアとゲートを操作  
• 保存した認証情報で素早くログイン（任意）  
• 🔐 Face ID / Touch IDによる任意の保護  
• ローカルネットワーク内だけで動作  
• タッチ操作に最適化されたクリーンなインターフェイス  
• クラウド接続は不要  

---

## 設定

GateTapは上級ユーザー向けで、手動設定が必要です:

1. デバイスのローカルIPアドレスを入力します  
2. ログイン認証情報を入力します  
3. 接続をテストしてシステムの操作を開始します  

GateTapは、内蔵Webインターフェイスを公開するシステムで動作します。互換性はハードウェア構成によって異なります。

完全な[設定ガイド](../setup-guide/setup-guide.ja.md)を読む.

---

## プライバシー優先

データはデバイス内に保存されます。GateTapは認証情報やコマンドを外部サーバーへ送信しません。

任意のクラッシュレポートはいつでも無効にできます。

完全な[プライバシーポリシー](../legal/ja/privacy-policy.ja.md)と[利用規約](../legal/ja/terms-of-use.ja.md)を読む。
