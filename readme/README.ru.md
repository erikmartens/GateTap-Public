_**Современный интерфейс iPhone для совместимых систем контроля доступа с веб-управлением.**_

Контроллер доступа — это устройство, которое электронно управляет открытием дверей, ворот, гаражей или шлагбаумов, например активируя дверной зуммер через домофонную систему или управляя мотором ворот.

Многие современные системы контроля доступа подключены к локальной сети и могут управляться через веб-интерфейс. Однако такие интерфейсы часто медленные, сложные и неудобные в использовании. GateTap заменяет устаревшие веб-страницы быстрым, оптимизированным для касаний интерфейсом, разработанным для iPhone.

GateTap создан для локальных сетей и подключается напрямую к совместимым контроллерам доступа — без облачных сервисов, подписок или внешних аккаунтов.

• 🖥️ Разработано для встроенных контроллеров с веб-управлением  
• 🏢 Поддержка нескольких контроллеров / нескольких объектов

## Совместимость

GateTap разработан для некоторых контроллеров доступа с Ethernet или Wi‑Fi, которые предоставляют встроенный браузерный интерфейс управления.

Совместимые системы обычно предоставляют:
- локальный доступ по IP
- встроенные страницы веб-администрирования
- вход через браузер
- управление реле или доступом через веб-интерфейс

Совместимость зависит от:
- модели контроллера
- версии прошивки
- структуры веб-интерфейса
- конфигурации сети

### Не совместимо с

GateTap, как правило, **не совместим** с:
- системами только с облачным управлением
- системами только с Bluetooth
- автономными ИК-пультами
- контроллерами доступа без веб-интерфейсов
- универсальными считывателями без сетевых модулей

[Посмотрите известный список совместимых устройств.](../support/ru/compatibility.ru.md)

## Попробуйте перед покупкой

GateTap можно бесплатно скачать и настроить, чтобы перед покупкой проверить совместимость с вашей системой.

Бесплатная версия позволяет:
- подключиться к контроллеру
- проверить учётные данные для входа
- протестировать совместимость
- предварительно просмотреть интерфейс контроллера

Единовременная покупка в приложении разблокирует:
- открытие ворот и дверей
- полноценное рабочее использование контроллера
- поддержку нескольких контроллеров / нескольких объектов
- будущие расширенные функции

Подписка не требуется.

## Настройка

GateTap предназначен для технически опытных пользователей и требует ручной настройки.

1. Введите локальный IP-адрес контроллера  
2. Укажите свои учётные данные для входа  
3. Проверьте соединение  
4. Разблокируйте полную функциональность и начните управлять системой напрямую с iPhone  

Прочитайте полное [руководство по настройке](../setup-guide/setup-guide.ru.md).

## Поддержка и помощь с совместимостью

Поскольку оборудование контроля доступа значительно различается у разных производителей и версий прошивки, совместимость не может быть гарантирована для всех систем.

Если ваш контроллер сейчас не поддерживается, поддержка всё ещё может быть возможна.

Пользователи могут обратиться в поддержку и предоставить:
- скриншоты веб-интерфейса контроллера
- экспортированные HTML-страницы
- информацию о модели контроллера
- сведения о прошивке

Когда это возможно, улучшения совместимости могут разрабатываться и тестироваться совместно с пользователями через бета-сборки TestFlight.

Обратите внимание, что этот процесс может быть техническим и может требовать активного сотрудничества во время тестирования.

## Конфиденциальность прежде всего

Ваши данные остаются на вашем устройстве.

GateTap не отправляет:
- учётные данные
- команды
- данные контроллера

на внешние серверы.

Опциональную отправку отчётов о сбоях можно отключить в любое время.
