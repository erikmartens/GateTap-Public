_**Хватит мучиться с устаревшими веб-интерфейсами.**_

Многие системы контроля доступа используют медленные и неудобные страницы браузера просто для открытия двери или ворот. GateTap дает быстрый, современный и удобный для сенсорного управления способ контролировать систему прямо с iPhone.

GateTap создан для локальных сетей и подключается напрямую к вашему контроллеру доступа — без облака, без учетных записей и без задержек.

---

## Возможности

• Управление дверями и воротами одним касанием  
• Быстрый вход с сохраненными учетными данными (необязательно)  
• 🔐 Дополнительная защита Face ID / Touch ID  
• Полностью работает внутри вашей локальной сети  
• Чистый интерфейс, оптимизированный для сенсорного управления  
• Подключение к облаку не требуется  

---

## Настройка

GateTap рассчитан на опытных пользователей и требует ручной настройки:

1. Введите локальный IP-адрес устройства  
2. Укажите учетные данные для входа  
3. Проверьте соединение и начните управлять системой  

GateTap работает с системами, которые предоставляют встроенный веб-интерфейс. Совместимость зависит от конфигурации оборудования.

Прочитайте полное [руководство по настройке](../setup-guide/setup-guide.ru.md).

---

## Сначала конфиденциальность

Ваши данные остаются на устройстве. GateTap не отправляет учетные данные или команды на внешние серверы.

Необязательную отправку отчетов о сбоях можно отключить в любое время.

Прочитайте полную [Политику конфиденциальности](../legal/ru/privacy-policy.ru.md) и [Условия использования](../legal/ru/terms-of-use.ru.md).
