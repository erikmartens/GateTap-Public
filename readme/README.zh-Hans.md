_**告别过时的网页界面。**_

许多门禁系统只是为了打开门或大门，就需要使用缓慢且难用的浏览器页面。GateTap 让你可以直接在 iPhone 上以快速、现代、适合触控的方式控制系统。

GateTap 面向本地网络而设计，可直接连接到你的门禁控制器 — 无需云端、无需账号、没有延迟。

---

## 功能

• 一键控制门和大门  
• 使用已保存的凭据快速登录（可选）  
• 🔐 可选 Face ID / Touch ID 保护  
• 完全在你的本地网络内运行  
• 简洁、适合触控的界面  
• 无需云连接  

---

## 设置

GateTap 面向高级用户，需要手动设置：

1. 输入设备的本地 IP 地址  
2. 提供你的登录凭据  
3. 测试连接并开始控制系统  

GateTap 适用于提供内置网页界面的系统。兼容性取决于你的硬件配置。

阅读完整的[设置指南](../setup-guide/setup-guide.zh-Hans.md).

---

## 隐私优先

你的数据保留在你的设备上。GateTap 不会将你的凭据或控制命令发送到外部服务器。

可选的崩溃报告可随时关闭。

阅读完整的[隐私政策](../legal/zh-Hans/privacy-policy.zh-Hans.md)和[使用条款](../legal/zh-Hans/terms-of-use.zh-Hans.md)。
