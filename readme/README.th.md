# GateTap

_**อินเทอร์เฟซ iPhone สมัยใหม่สำหรับระบบควบคุมการเข้าออกที่รองรับและจัดการผ่านเว็บ**_

ตัวควบคุมการเข้าออกคืออุปกรณ์ที่จัดการการเปิดประตู ประตูรั้ว โรงรถ หรือไม้กั้นด้วยระบบอิเล็กทรอนิกส์ เช่น สั่งงานกริ่งเปิดประตูผ่านระบบอินเตอร์คอม หรือควบคุมมอเตอร์ประตูรั้ว

ระบบควบคุมการเข้าออกสมัยใหม่จำนวนมากเชื่อมต่อกับเครือข่ายภายในและควบคุมได้ผ่านอินเทอร์เฟซเว็บ อย่างไรก็ตาม อินเทอร์เฟซเหล่านี้มักช้า ใช้งานยาก และไม่สะดวก GateTap แทนที่หน้าเว็บแบบเก่าด้วยประสบการณ์ที่รวดเร็ว เหมาะกับการสัมผัส และออกแบบมาสำหรับ iPhone

GateTap สร้างขึ้นสำหรับเครือข่ายภายใน และเชื่อมต่อโดยตรงกับตัวควบคุมการเข้าออกที่รองรับ — โดยไม่ต้องใช้บริการคลาวด์ การสมัครสมาชิก หรือบัญชีภายนอก

## คุณสมบัติ

• ☑️ การควบคุมประตูรั้วและประตูที่ทันสมัย  
• 📱 อินเทอร์เฟซใช้งานง่ายและเหมาะกับการสัมผัส  
• ⚡ เข้าสู่ระบบรวดเร็วด้วยข้อมูลรับรองที่จัดเก็บอย่างปลอดภัย หรือข้อมูลรับรองเซสชันชั่วคราว  
• 🔐 การป้องกันแอปด้วย Face ID / Touch ID แบบเลือกได้  
• 📡 สื่อสารโดยตรงผ่านเครือข่ายภายใน  
• ☁️ ไม่ต้องใช้การเชื่อมต่อคลาวด์  
• 🖥️ ออกแบบมาสำหรับตัวควบคุมแบบฝังตัวที่จัดการผ่านเว็บ  
• 🏢 รองรับหลายตัวควบคุม / หลายสถานที่

## ความเข้ากันได้

GateTap ออกแบบมาสำหรับตัวควบคุมการเข้าออกบางรุ่นที่รองรับ Ethernet หรือ Wi‑Fi และมีอินเทอร์เฟซจัดการในตัวผ่านเบราว์เซอร์

ระบบที่รองรับโดยทั่วไปจะมี:
- การเข้าถึงภายในผ่าน IP
- หน้าเว็บสำหรับดูแลระบบในตัว
- ฟังก์ชันเข้าสู่ระบบผ่านเบราว์เซอร์
- การควบคุมรีเลย์หรือการเข้าออกผ่านอินเทอร์เฟซเว็บ

ความเข้ากันได้ขึ้นอยู่กับ:
- รุ่นของตัวควบคุม
- เวอร์ชันเฟิร์มแวร์
- โครงสร้างอินเทอร์เฟซเว็บ
- การตั้งค่าเครือข่าย

### ไม่รองรับ

โดยทั่วไป GateTap **ไม่รองรับ**:
- ระบบที่ใช้คลาวด์เท่านั้น
- ระบบที่ใช้ Bluetooth เท่านั้น
- รีโมต IR แบบแยกเดี่ยว
- ตัวควบคุมการเข้าออกที่ไม่มีอินเทอร์เฟซเว็บ
- เครื่องอ่านทั่วไปที่ไม่มีโมดูลเครือข่าย

## ทดลองก่อนซื้อ

สามารถดาวน์โหลดและตั้งค่า GateTap ได้ฟรี เพื่อให้คุณตรวจสอบความเข้ากันได้กับระบบของคุณก่อนซื้อ

เวอร์ชันฟรีช่วยให้คุณ:
- เชื่อมต่อกับตัวควบคุมของคุณ
- ตรวจสอบข้อมูลเข้าสู่ระบบ
- ทดสอบความเข้ากันได้
- ดูตัวอย่างอินเทอร์เฟซของตัวควบคุม

การซื้อภายในแอปแบบครั้งเดียวจะปลดล็อก:
- การสั่งงานประตูรั้วและประตู
- การใช้งานตัวควบคุมเต็มรูปแบบ
- การรองรับหลายตัวควบคุม / หลายสถานที่
- คุณสมบัติขั้นสูงในอนาคต

ไม่ต้องสมัครสมาชิก

## การตั้งค่า

GateTap เหมาะสำหรับผู้ใช้ที่มีประสบการณ์ด้านเทคนิค และต้องตั้งค่าด้วยตนเอง

1. ป้อนที่อยู่ IP ภายในของตัวควบคุม  
2. ระบุข้อมูลเข้าสู่ระบบของคุณ  
3. ทดสอบการเชื่อมต่อ  
4. ปลดล็อกฟังก์ชันเต็มรูปแบบและเริ่มควบคุมระบบโดยตรงจาก iPhone  

อ่าน[คู่มือการตั้งค่า](../setup-guide/setup-guide.th.md)ฉบับเต็ม

## การสนับสนุนและความช่วยเหลือด้านความเข้ากันได้

เนื่องจากฮาร์ดแวร์ควบคุมการเข้าออกแตกต่างกันมากตามผู้ผลิตและเวอร์ชันเฟิร์มแวร์ จึงไม่สามารถรับประกันความเข้ากันได้กับทุกระบบ

หากตัวควบคุมของคุณยังไม่รองรับในขณะนี้ อาจยังสามารถเพิ่มการรองรับได้

ผู้ใช้สามารถติดต่อฝ่ายสนับสนุนและให้ข้อมูลดังนี้:
- ภาพหน้าจอของอินเทอร์เฟซเว็บของตัวควบคุม
- หน้า HTML ที่ส่งออก
- ข้อมูลรุ่นของตัวควบคุม
- รายละเอียดเฟิร์มแวร์

เมื่อทำได้ อาจมีการพัฒนาและทดสอบการปรับปรุงความเข้ากันได้ร่วมกับผู้ใช้ผ่านรุ่นเบต้า TestFlight

โปรดทราบว่ากระบวนการนี้อาจมีความเป็นเทคนิค และอาจต้องอาศัยความร่วมมือระหว่างการทดสอบ
