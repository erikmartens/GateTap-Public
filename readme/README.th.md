_**เลิกฝืนใช้เว็บอินเทอร์เฟซที่ล้าสมัยได้แล้ว**_

ระบบควบคุมการเข้าออกจำนวนมากยังพึ่งพาหน้าเว็บที่ช้าและใช้งานยากเพียงเพื่อเปิดประตูหรือประตูรั้ว GateTap ช่วยให้คุณควบคุมระบบได้อย่างรวดเร็ว ทันสมัย และเหมาะกับการสัมผัสโดยตรงจาก iPhone

GateTap สร้างมาสำหรับเครือข่ายภายใน และเชื่อมต่อโดยตรงกับตัวควบคุมการเข้าออกของคุณ — ไม่ต้องใช้คลาวด์ ไม่ต้องมีบัญชี และไม่มีความล่าช้า

---

## คุณสมบัติ

• ควบคุมประตูและประตูรั้วด้วยการแตะครั้งเดียว  
• เข้าสู่ระบบอย่างรวดเร็วด้วยข้อมูลรับรองที่บันทึกไว้ (ไม่บังคับ)  
• 🔐 การป้องกันเพิ่มเติมด้วย Face ID / Touch ID  
• ทำงานทั้งหมดภายในเครือข่ายท้องถิ่นของคุณ  
• อินเทอร์เฟซสะอาดและเหมาะกับการสัมผัส  
• ไม่ต้องใช้การเชื่อมต่อคลาวด์  

---

## การตั้งค่า

GateTap ออกแบบมาสำหรับผู้ใช้ขั้นสูงและต้องตั้งค่าด้วยตนเอง:

1. ป้อนที่อยู่ IP ภายในของอุปกรณ์  
2. ป้อนข้อมูลเข้าสู่ระบบของคุณ  
3. ทดสอบการเชื่อมต่อและเริ่มควบคุมระบบ  

GateTap ทำงานกับระบบที่มีเว็บอินเทอร์เฟซในตัว ความเข้ากันได้ขึ้นอยู่กับการกำหนดค่าฮาร์ดแวร์ของคุณ

อ่าน[คู่มือการตั้งค่า](../setup-guide/setup-guide.th.md)ฉบับเต็ม.

## ให้ความสำคัญกับความเป็นส่วนตัว

ข้อมูลของคุณอยู่บนอุปกรณ์ของคุณ GateTap ไม่ส่งข้อมูลรับรองหรือคำสั่งไปยังเซิร์ฟเวอร์ภายนอก

คุณสามารถปิดการรายงานข้อขัดข้องแบบไม่บังคับได้ทุกเมื่อ
