_**Deja de pelearte con interfaces web obsoletas.**_

Muchos sistemas de control de acceso dependen de páginas web lentas y difíciles de usar solo para abrir una puerta o un portón. GateTap te ofrece una forma rápida, moderna y táctil de controlar tu sistema directamente desde el iPhone.

Diseñada para redes locales, GateTap se conecta directamente a tu controlador de acceso: sin nube, sin cuentas y sin demoras.

---

## Funciones

• Control de puertas y portones con un toque  
• Inicio de sesión rápido con credenciales guardadas (opcional)  
• 🔐 Protección opcional con Face ID / Touch ID  
• Funciona por completo dentro de tu red local  
• Interfaz limpia y optimizada para el tacto  
• No requiere conexión a la nube  

---

## Configuración

GateTap está pensada para usuarios avanzados y requiere configuración manual:

1. Introduce la dirección IP local del dispositivo  
2. Introduce tus credenciales de inicio de sesión  
3. Prueba la conexión y empieza a controlar tu sistema  

GateTap funciona con sistemas que exponen una interfaz web integrada. La compatibilidad depende de la configuración de tu hardware.

Lee la [Guía de configuración](../setup-guide/setup-guide.es.md) completa.

## Privacidad ante todo

Tus datos permanecen en tu dispositivo. GateTap no envía tus credenciales ni comandos a servidores externos.

Los informes de fallos opcionales se pueden desactivar en cualquier momento.
