_**पुराने वेब इंटरफ़ेस से जूझना बंद करें।**_

कई एक्सेस कंट्रोल सिस्टम केवल दरवाज़ा या गेट खोलने के लिए धीमे और कठिन ब्राउज़र पेजों पर निर्भर होते हैं। GateTap आपके iPhone से सीधे सिस्टम नियंत्रित करने का तेज़, आधुनिक और टच-अनुकूल तरीका देता है।

स्थानीय नेटवर्क के लिए बनाया गया GateTap सीधे आपके एक्सेस कंट्रोलर से जुड़ता है — कोई क्लाउड नहीं, कोई खाते नहीं, कोई देरी नहीं।

---

## विशेषताएँ

• एक टैप से दरवाज़ा और गेट नियंत्रण  
• सहेजे गए क्रेडेंशियल के साथ तेज़ लॉगिन (वैकल्पिक)  
• 🔐 वैकल्पिक Face ID / Touch ID सुरक्षा  
• पूरी तरह आपके स्थानीय नेटवर्क में काम करता है  
• स्वच्छ, टच-अनुकूल इंटरफ़ेस  
• क्लाउड कनेक्शन की आवश्यकता नहीं  

---

## सेटअप

GateTap उन्नत उपयोगकर्ताओं के लिए बनाया गया है और मैनुअल सेटअप की आवश्यकता होती है:

1. डिवाइस का स्थानीय IP पता दर्ज करें  
2. अपने लॉगिन क्रेडेंशियल दें  
3. कनेक्शन जाँचें और सिस्टम नियंत्रित करना शुरू करें  

GateTap उन सिस्टमों के साथ काम करता है जो अंतर्निहित वेब इंटरफ़ेस प्रदान करते हैं। संगतता आपके हार्डवेयर कॉन्फ़िगरेशन पर निर्भर करती है।

पूरी [सेटअप गाइड](../setup-guide/setup-guide.hi.md) पढ़ें.
