_**Prestaňte bojovať so zastaranými webovými rozhraniami.**_

Mnohé systémy kontroly prístupu sa spoliehajú na pomalé a ťažkopádne webové stránky len preto, aby otvorili dvere alebo bránu. GateTap ponúka rýchly, moderný a dotykovo prívetivý spôsob ovládania priamo z iPhonu.

GateTap je vytvorený pre lokálne siete a pripája sa priamo k vášmu prístupovému kontroléru — bez cloudu, bez účtov a bez oneskorení.

---

## Funkcie

• Ovládanie dverí a brán jedným ťuknutím  
• Rýchle prihlásenie s uloženými údajmi (voliteľné)  
• 🔐 Voliteľná ochrana Face ID / Touch ID  
• Funguje výhradne vo vašej lokálnej sieti  
• Čisté rozhranie optimalizované na dotyk  
• Nevyžaduje cloudové pripojenie  

---

## Nastavenie

GateTap je určený pre pokročilých používateľov a vyžaduje manuálne nastavenie:

1. Zadajte lokálnu IP adresu zariadenia  
2. Zadajte prihlasovacie údaje  
3. Otestujte pripojenie a začnite systém ovládať  

GateTap funguje so systémami, ktoré poskytujú zabudované webové rozhranie. Kompatibilita závisí od konfigurácie hardvéru.

Prečítajte si celý [sprievodca nastavením](../setup-guide/setup-guide.sk.md).

## Súkromie na prvom mieste

Vaše údaje zostávajú vo vašom zariadení. GateTap neposiela prihlasovacie údaje ani príkazy na externé servery.

Voliteľné hlásenie pádov môžete kedykoľvek vypnúť.

Prečítajte si celé [zásady ochrany osobných údajov](../legal/sk/privacy-policy.sk.md) a [podmienky používania](../legal/sk/terms-of-use.sk.md).
