# GateTap

_**Moderné rozhranie pre iPhone pre kompatibilné webovo spravované systémy kontroly prístupu.**_

Riadiaca jednotka prístupu je zariadenie, ktoré elektronicky spravuje otváranie dverí, brán, garáží alebo závor — napríklad aktivovaním dverového bzučiaka cez domový telefón alebo ovládaním motora brány.

Mnohé moderné systémy kontroly prístupu sú pripojené k lokálnej sieti a možno ich ovládať cez webové rozhranie. Tieto rozhrania sú však často pomalé, náročné a nepohodlné na používanie. GateTap nahrádza zastarané webové stránky rýchlym, dotykovo optimalizovaným prostredím navrhnutým pre iPhone.

GateTap je vytvorený pre lokálne siete a pripája sa priamo ku kompatibilným riadiacim jednotkám prístupu — bez cloudových služieb, predplatného alebo externých účtov.

---

## Funkcie

• ☑️ Moderné ovládanie brán a dverí  
• 📱 Intuitívne rozhranie optimalizované pre dotyk  
• ⚡ Rýchle prihlásenie s bezpečne uloženými prihlasovacími údajmi alebo dočasnými údajmi relácie  
• 🔐 Voliteľná ochrana aplikácie cez Face ID / Touch ID  
• 📡 Priama komunikácia v lokálnej sieti  
• ☁️ Nevyžaduje sa cloudové pripojenie  
• 🖥️ Navrhnuté pre vstavané webovo spravované riadiace jednotky  
• 🏢 Podpora viacerých riadiacich jednotiek / viacerých lokalít  

---

## Kompatibilita

GateTap je navrhnutý pre určité riadiace jednotky prístupu s Ethernetom alebo Wi‑Fi, ktoré poskytujú vstavané rozhranie správy v prehliadači.

Kompatibilné systémy zvyčajne poskytujú:
- lokálny prístup cez IP
- vstavané webové administračné stránky
- prihlasovanie cez prehliadač
- ovládanie relé alebo prístupu cez webové rozhranie

Kompatibilita závisí od:
- modelu riadiacej jednotky
- verzie firmvéru
- štruktúry webového rozhrania
- konfigurácie siete

### Nie je kompatibilné s

GateTap vo všeobecnosti **nie je kompatibilný** s:
- systémami iba v cloude
- systémami iba cez Bluetooth
- samostatnými IR ovládačmi
- riadiacimi jednotkami prístupu bez webových rozhraní
- generickými čítačkami bez sieťových modulov

## Vyskúšajte pred nákupom

GateTap si môžete bezplatne stiahnuť a nakonfigurovať, aby ste si pred nákupom overili kompatibilitu so svojím systémom.

Bezplatná verzia umožňuje:
- pripojiť sa k riadiacej jednotke
- overiť prihlasovacie údaje
- otestovať kompatibilitu
- zobraziť náhľad rozhrania riadiacej jednotky

Jednorazový nákup v aplikácii odomkne:
- spúšťanie brán a dverí
- plné prevádzkové používanie riadiacej jednotky
- podporu viacerých riadiacich jednotiek / viacerých lokalít
- budúce pokročilé funkcie

Nevyžaduje sa predplatné.

## Nastavenie

GateTap je určený pre technicky skúsených používateľov a vyžaduje manuálnu konfiguráciu.

1. Zadajte lokálnu IP adresu riadiacej jednotky  
2. Zadajte svoje prihlasovacie údaje  
3. Otestujte pripojenie  
4. Odomknite plnú funkčnosť a začnite ovládať systém priamo z iPhonu  

Prečítajte si celú [príručku nastavenia](../setup-guide/setup-guide.sk.md).

## Podpora a pomoc s kompatibilitou

Keďže hardvér kontroly prístupu sa výrazne líši podľa výrobcov a verzií firmvéru, kompatibilitu nemožno zaručiť pre všetky systémy.

Ak vaša riadiaca jednotka momentálne nie je podporovaná, podpora môže byť stále možná.

Používatelia môžu kontaktovať podporu a poskytnúť:
- snímky obrazovky webového rozhrania riadiacej jednotky
- exportované HTML stránky
- informácie o modeli riadiacej jednotky
- podrobnosti o firmvéri

Ak je to realizovateľné, vylepšenia kompatibility môžu byť vyvíjané a testované spolu s používateľmi prostredníctvom beta verzií TestFlight.

Upozorňujeme, že tento proces môže byť technický a môže vyžadovať aktívnu spoluprácu počas testovania.
