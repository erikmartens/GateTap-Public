_**適用於相容 Web 管理型門禁系統的現代 iPhone 介面。**_

門禁控制器是一種以電子方式管理門、閘門、車庫門或柵欄開啟的裝置，例如透過對講系統啟動門鈴開關，或控制閘門馬達。

許多現代門禁系統已連接到本機網路，並可透過 Web 介面控制。然而，這些介面通常速度慢、難用且操作繁瑣。GateTap 以專為 iPhone 設計的快速、觸控最佳化體驗取代過時的網頁。

GateTap 專為本機網路打造，可直接連接相容的門禁控制器，無需雲端服務、訂閱或外部帳號。

---

## 功能

• ☑️ 現代化閘門與門控制  
• 📱 直覺、觸控最佳化介面  
• ⚡ 使用安全儲存的憑證或暫時工作階段憑證快速登入  
• 🔐 可選的 Face ID / Touch ID App 保護  
• 📡 直接本機網路通訊  
• ☁️ 不需要雲端連線  
• 🖥️ 專為嵌入式 Web 管理控制器設計  
• 🏢 支援多控制器 / 多站點  

---

## 相容性

GateTap 專為某些支援 Ethernet 或 Wi‑Fi，並提供內建瀏覽器式管理介面的門禁控制器設計。

相容系統通常提供：
- 本機 IP 存取
- 內建 Web 管理頁面
- 瀏覽器登入功能
- 透過 Web 介面進行繼電器或門禁控制

相容性取決於：
- 控制器型號
- 韌體版本
- Web 介面結構
- 網路設定

### 不相容

GateTap 通常**不相容**於：
- 僅雲端系統
- 僅 Bluetooth 系統
- 獨立 IR 遙控器
- 沒有 Web 介面的門禁控制器
- 沒有網路模組的一般讀卡機

[查看已知相容裝置清單。](../support/zh-Hant/compatibility.zh-Hant.md)

## 設定

GateTap 適合具備技術經驗的使用者，並需要手動設定。

1. 輸入控制器的本機 IP 位址  
2. 提供登入憑證  
3. 測試連線  
4. 解鎖完整功能，並開始直接從 iPhone 控制系統  

閱讀完整的[設定指南](../setup-guide/setup-guide.zh-Hant.md)。

## 支援與相容性協助

由於門禁硬體在不同製造商與韌體版本之間差異很大，因此無法保證與所有系統相容。

如果你的控制器目前不受支援，仍可能可以提供支援。

使用者可以聯絡支援並提供：
- 控制器 Web 介面的螢幕截圖
- 匯出的 HTML 頁面
- 控制器型號資訊
- 韌體詳細資訊

可行時，可透過 TestFlight 測試版與使用者共同開發並測試相容性改進。

請注意，此流程可能具有技術性，並可能需要在測試期間積極合作。
