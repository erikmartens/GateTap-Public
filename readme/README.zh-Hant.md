_**告別過時的網頁介面。**_

許多門禁系統只是為了開門或開啟大門，就需要使用緩慢且難用的瀏覽器頁面。GateTap 讓你可以直接在 iPhone 上，以快速、現代且適合觸控的方式控制系統。

GateTap 為本地網路而設計，可直接連線到你的門禁控制器 — 無需雲端、無需帳號、沒有延遲。

---

## 功能

• 一鍵控制門與大門  
• 使用已儲存的憑證快速登入（選用）  
• 🔐 可選 Face ID / Touch ID 保護  
• 完全在你的本地網路內運作  
• 簡潔、適合觸控的介面  
• 不需要雲端連線  

---

## 設定

GateTap 適合進階使用者，並需要手動設定：

1. 輸入裝置的本地 IP 位址  
2. 提供你的登入憑證  
3. 測試連線並開始控制系統  

GateTap 適用於提供內建網頁介面的系統。相容性取決於你的硬體設定。

閱讀完整的[設定指南](../setup-guide/setup-guide.zh-Hant.md).

---

## 隱私優先

你的資料會保留在你的裝置上。GateTap 不會將你的憑證或控制命令傳送到外部伺服器。

可選的當機回報可隨時停用。

閱讀完整的[隱私權政策](../legal/zh-Hant/privacy-policy.zh-Hant.md)與[使用條款](../legal/zh-Hant/terms-of-use.zh-Hant.md)。
