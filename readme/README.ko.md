_**낡은 웹 인터페이스와 씨름하지 마세요.**_

많은 출입 제어 시스템은 문이나 게이트를 열기 위해 느리고 사용하기 어려운 브라우저 페이지에 의존합니다. GateTap은 iPhone에서 직접 시스템을 제어할 수 있는 빠르고 현대적이며 터치 친화적인 방법을 제공합니다.

로컬 네트워크용으로 설계된 GateTap은 액세스 컨트롤러에 직접 연결됩니다. 클라우드도, 계정도, 지연도 없습니다.

---

## 기능

• 한 번의 탭으로 문과 게이트 제어  
• 저장된 자격 증명으로 빠른 로그인(선택 사항)  
• 🔐 Face ID / Touch ID 선택 보호  
• 로컬 네트워크 내에서만 작동  
• 깔끔하고 터치에 최적화된 인터페이스  
• 클라우드 연결 불필요  

---

## 설정

GateTap은 고급 사용자를 위해 설계되었으며 수동 설정이 필요합니다:

1. 기기의 로컬 IP 주소 입력  
2. 로그인 자격 증명 입력  
3. 연결을 테스트하고 시스템 제어 시작  

GateTap은 내장 웹 인터페이스를 제공하는 시스템에서 작동합니다. 호환성은 하드웨어 구성에 따라 달라집니다.

전체 [설정 가이드](../setup-guide/setup-guide.ko.md) 읽기.
