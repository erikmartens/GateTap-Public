# GateTap

_**Сучасний інтерфейс iPhone для сумісних систем контролю доступу з вебкеруванням.**_

Контролер доступу — це пристрій, який електронно керує відкриванням дверей, воріт, гаражів або шлагбаумів, наприклад активуючи дверний дзвінок через домофонну систему або керуючи мотором воріт.

Багато сучасних систем контролю доступу підключені до локальної мережі та можуть керуватися через вебінтерфейс. Однак такі інтерфейси часто повільні, складні й незручні у використанні. GateTap замінює застарілі вебсторінки швидким, оптимізованим для дотику інтерфейсом, розробленим для iPhone.

GateTap створено для локальних мереж і він підключається безпосередньо до сумісних контролерів доступу — без хмарних сервісів, підписок або зовнішніх облікових записів.

• 🏢 Підтримка кількох контролерів / кількох об’єктів

## Сумісність

GateTap розроблено для певних контролерів доступу з Ethernet або Wi‑Fi, які мають вбудований браузерний інтерфейс адміністрування.

Сумісні системи зазвичай надають:
- локальний доступ на основі IP
- вбудовані сторінки вебадміністрування
- функцію входу через браузер
- керування реле або доступом через вебінтерфейс

Сумісність залежить від:
- моделі контролера
- версії прошивки
- структури вебінтерфейсу
- конфігурації мережі

### Не сумісно з

GateTap загалом **не сумісний** із:
- системами лише з хмарним керуванням
- системами лише Bluetooth
- автономними ІЧ-пультами
- контролерами доступу без вебінтерфейсів
- універсальними зчитувачами без мережевих модулів

## Спробуйте перед покупкою

GateTap можна безкоштовно завантажити й налаштувати, щоб перед покупкою перевірити сумісність із вашою системою.

Безкоштовна версія дозволяє:
- підключитися до контролера
- перевірити облікові дані для входу
- протестувати сумісність
- попередньо переглянути інтерфейс контролера

Одноразова покупка в застосунку розблоковує:
- запуск воріт і дверей
- повне робоче використання контролера
- підтримку кількох контролерів / кількох об’єктів
- майбутні розширені функції

Підписка не потрібна.

## Налаштування

GateTap призначений для технічно досвідчених користувачів і потребує ручного налаштування.

1. Введіть локальну IP-адресу контролера  
2. Надайте свої облікові дані для входу  
3. Перевірте з’єднання  
4. Розблокуйте повну функціональність і почніть керувати системою безпосередньо з iPhone  

Прочитайте повний [посібник із налаштування](../setup-guide/setup-guide.uk.md).

## Підтримка та допомога із сумісністю

Оскільки обладнання контролю доступу суттєво відрізняється між виробниками та версіями прошивки, сумісність не може бути гарантована для всіх систем.

Якщо ваш контролер наразі не підтримується, підтримка все ще може бути можливою.

Користувачі можуть звернутися до підтримки та надати:
- знімки екрана вебінтерфейсу контролера
- експортовані HTML-сторінки
- інформацію про модель контролера
- відомості про прошивку

Коли це можливо, покращення сумісності можуть розроблятися й тестуватися разом із користувачами через бета-збірки TestFlight.

Зверніть увагу, що цей процес може бути технічним і може вимагати активної співпраці під час тестування.
