_**Досить боротися із застарілими вебінтерфейсами.**_

Багато систем контролю доступу покладаються на повільні та незручні сторінки браузера лише для відкриття дверей або воріт. GateTap дає швидкий, сучасний і зручний для дотику спосіб керувати системою безпосередньо з iPhone.

GateTap створено для локальних мереж і він підключається безпосередньо до вашого контролера доступу — без хмари, без облікових записів і без затримок.

---

## Можливості

• Керування дверима й воротами одним дотиком  
• Швидкий вхід зі збереженими обліковими даними (необов’язково)  
• 🔐 Додатковий захист Face ID / Touch ID  
• Працює повністю у вашій локальній мережі  
• Чистий інтерфейс, оптимізований для дотику  
• Не потребує хмарного підключення  

---

## Налаштування

GateTap призначено для досвідчених користувачів і потребує ручного налаштування:

1. Введіть локальну IP-адресу пристрою  
2. Надайте свої облікові дані для входу  
3. Перевірте підключення й почніть керувати системою  

GateTap працює із системами, які мають вбудований вебінтерфейс. Сумісність залежить від конфігурації вашого обладнання.

Прочитайте повний [посібник із налаштування](../setup-guide/setup-guide.uk.md).
