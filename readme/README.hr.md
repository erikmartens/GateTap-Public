_**Moderno iPhone sučelje za kompatibilne web-upravljane sustave kontrole pristupa.**_

Kontroler pristupa je uređaj koji elektronički upravlja otvaranjem vrata, kapija, garaža ili rampi — primjerice aktiviranjem zvona za vrata putem portafona ili upravljanjem motorom kapije.

Mnogi moderni sustavi kontrole pristupa povezani su s lokalnom mrežom i mogu se upravljati putem web sučelja. Međutim, ta sučelja često su spora, teška i nezgrapna za korištenje. GateTap zamjenjuje zastarjele web stranice brzim iskustvom optimiziranim za dodir i dizajniranim za iPhone.

Izgrađen za lokalne mreže, GateTap se izravno povezuje s kompatibilnim kontrolerima pristupa — bez cloud usluga, pretplata ili vanjskih računa.

## Kompatibilnost

GateTap je dizajniran za određene Ethernet ili Wi‑Fi kontrolere pristupa koji imaju ugrađeno administracijsko sučelje temeljeno na pregledniku.

Kompatibilni sustavi obično pružaju:
- lokalni pristup temeljen na IP-u
- ugrađene web administracijske stranice
- prijavu putem preglednika
- upravljanje relejem ili pristupom putem web sučelja

Kompatibilnost ovisi o:
- modelu kontrolera
- verziji firmvera
- strukturi web sučelja
- mrežnoj konfiguraciji

### Nije kompatibilno s

GateTap općenito **nije kompatibilan** s:
- sustavima samo u cloudu
- sustavima samo putem Bluetootha
- samostalnim IR daljinskim upravljačima
- kontrolerima pristupa bez web sučelja
- generičkim čitačima bez mrežnih modula

[Pogledajte poznati popis kompatibilnih uređaja.](../support/hr/compatibility.hr.md)

## Isprobajte prije kupnje

GateTap se može besplatno preuzeti i konfigurirati kako biste prije kupnje provjerili kompatibilnost sa svojim sustavom.

Besplatna verzija omogućuje vam:
- povezivanje s kontrolerom
- provjeru vjerodajnica za prijavu
- testiranje kompatibilnosti
- pregled sučelja kontrolera

Jednokratna kupnja unutar aplikacije otključava:
- aktiviranje kapija i vrata
- potpuno operativno korištenje kontrolera
- podršku za više kontrolera / više lokacija
- buduće napredne značajke

Pretplata nije potrebna.

## Postavljanje

GateTap je namijenjen tehnički iskusnim korisnicima i zahtijeva ručnu konfiguraciju.

1. Unesite lokalnu IP adresu kontrolera  
2. Unesite svoje vjerodajnice za prijavu  
3. Testirajte vezu  
4. Otključajte punu funkcionalnost i počnite upravljati sustavom izravno s iPhonea  

Pročitajte cijeli [vodič za postavljanje](../setup-guide/setup-guide.hr.md).

## Podrška i pomoć za kompatibilnost

Budući da se hardver za kontrolu pristupa znatno razlikuje među proizvođačima i verzijama firmvera, kompatibilnost se ne može jamčiti za sve sustave.

Ako vaš kontroler trenutačno nije podržan, podrška ipak može biti moguća.

Korisnici mogu kontaktirati podršku i dostaviti:
- snimke zaslona web sučelja kontrolera
- izvezene HTML stranice
- informacije o modelu kontrolera
- detalje o firmveru

Kada je izvedivo, poboljšanja kompatibilnosti mogu se razvijati i testirati zajedno s korisnicima putem TestFlight beta verzija.

Imajte na umu da ovaj proces može biti tehnički i može zahtijevati aktivnu suradnju tijekom testiranja.
