_**Eski web arayüzleriyle uğraşmayı bırakın.**_

Birçok erişim kontrol sistemi, yalnızca bir kapıyı veya geçidi açmak için yavaş ve kullanımı zor tarayıcı sayfalarına dayanır. GateTap, sisteminizi doğrudan iPhone’unuzdan hızlı, modern ve dokunmatik kullanıma uygun şekilde kontrol etmenizi sağlar.

Yerel ağlar için geliştirilen GateTap, erişim kontrol cihazınıza doğrudan bağlanır — bulut yok, hesap yok, gecikme yok.

---

## Özellikler

• Tek dokunuşla kapı ve geçit kontrolü  
• Kaydedilmiş kimlik bilgileriyle hızlı giriş (isteğe bağlı)  
• 🔐 İsteğe bağlı Face ID / Touch ID koruması  
• Tamamen yerel ağınız içinde çalışır  
• Temiz, dokunmatik için optimize edilmiş arayüz  
• Bulut bağlantısı gerekmez  

---

## Kurulum

GateTap ileri düzey kullanıcılar için tasarlanmıştır ve manuel kurulum gerektirir:

1. Cihazınızın yerel IP adresini girin  
2. Giriş kimlik bilgilerinizi sağlayın  
3. Bağlantıyı test edin ve sistemi kontrol etmeye başlayın  

GateTap, yerleşik web arayüzü sunan sistemlerle çalışır. Uyumluluk donanım yapılandırmanıza bağlıdır.

Tam [Kurulum Kılavuzu](../setup-guide/setup-guide.tr.md)nu okuyun.

Verileriniz cihazınızda kalır. GateTap kimlik bilgilerinizi veya komutlarınızı harici sunuculara göndermez.
