_**Uyumlu web üzerinden yönetilen erişim kontrol sistemleri için modern bir iPhone arayüzü.**_

Erişim kontrolörü, kapıların, giriş kapılarının, garajların veya bariyerlerin açılmasını elektronik olarak yöneten bir cihazdır — örneğin interkom sisteminiz üzerinden kapı zilini etkinleştirerek veya bir kapı motorunu kontrol ederek.

Birçok modern erişim kontrol sistemi yerel ağa bağlıdır ve bir web arayüzü üzerinden kontrol edilebilir. Ancak bu arayüzler çoğu zaman yavaş, zor ve kullanımı zahmetlidir. GateTap, eski web sayfalarını iPhone için tasarlanmış hızlı, dokunmaya optimize edilmiş bir deneyimle değiştirir.

Yerel ağlar için geliştirilen GateTap, uyumlu erişim kontrolörlerine doğrudan bağlanır — bulut hizmetleri, abonelikler veya harici hesaplar olmadan.

---

## Özellikler

• ☑️ Modern kapı ve giriş kontrolü  
• 📱 Sezgisel, dokunmaya optimize edilmiş arayüz  
• ⚡ Güvenli şekilde kaydedilmiş kimlik bilgileri veya geçici oturum kimlik bilgileriyle hızlı giriş  
• 🔐 Uygulama için isteğe bağlı Face ID / Touch ID koruması  
• 📡 Doğrudan yerel ağ iletişimi  
• ☁️ Bulut bağlantısı gerekmez  
• 🖥️ Gömülü web yönetimli kontrolörler için tasarlandı  
• 🏢 Çoklu kontrolör / çoklu konum desteği  

---

## Uyumluluk

GateTap, yerleşik tarayıcı tabanlı yönetim arayüzü sağlayan belirli Ethernet veya Wi‑Fi özellikli erişim kontrolörleri için tasarlanmıştır.

Uyumlu sistemler genellikle şunları sağlar:
- yerel IP tabanlı erişim
- yerleşik web yönetim sayfaları
- tarayıcı giriş işlevi
- web arayüzü üzerinden röle veya erişim kontrolü

Uyumluluk şunlara bağlıdır:
- kontrolör modeli
- donanım yazılımı sürümü
- web arayüzü yapısı
- ağ yapılandırması

### Uyumlu değildir

GateTap genel olarak şunlarla **uyumlu değildir**:
- yalnızca bulut tabanlı sistemler
- yalnızca Bluetooth sistemleri
- bağımsız IR kumandalar
- web arayüzü olmayan erişim kontrolörleri
- ağ modülü olmayan genel okuyucular

[Uyumlu cihazların bilinen listesini görün.](../support/tr/compatibility.tr.md)

## Satın almadan önce deneyin

GateTap ücretsiz olarak indirilebilir ve yapılandırılabilir; böylece satın almadan önce sisteminizle uyumluluğu doğrulayabilirsiniz.

Ücretsiz sürüm şunları yapmanıza olanak tanır:
- kontrolörünüze bağlanma
- giriş kimlik bilgilerini doğrulama
- uyumluluğu test etme
- kontrolör arayüzünü önizleme

Tek seferlik uygulama içi satın alma şunları açar:
- kapı ve giriş tetikleme
- kontrolörün tam operasyonel kullanımı
- çoklu kontrolör / çoklu konum desteği
- gelecekteki gelişmiş özellikler

Abonelik gerekmez.

## Kurulum

GateTap teknik deneyime sahip kullanıcılar için tasarlanmıştır ve manuel yapılandırma gerektirir.

1. Kontrolörünüzün yerel IP adresini girin  
2. Giriş kimlik bilgilerinizi sağlayın  
3. Bağlantıyı test edin  
4. Tam işlevselliğin kilidini açın ve sisteminizi doğrudan iPhone’unuzdan kontrol etmeye başlayın  

Tam [Kurulum Kılavuzu](../setup-guide/setup-guide.tr.md)nu okuyun.

## Destek ve uyumluluk yardımı

Erişim kontrol donanımı üreticiler ve donanım yazılımı sürümleri arasında önemli ölçüde değiştiğinden, tüm sistemler için uyumluluk garanti edilemez.

Kontrolörünüz şu anda desteklenmiyorsa, destek yine de mümkün olabilir.

Kullanıcılar destekle iletişime geçip şunları sağlayabilir:
- kontrolör web arayüzünün ekran görüntüleri
- dışa aktarılmış HTML sayfaları
- kontrolör model bilgisi
- donanım yazılımı ayrıntıları

Mümkün olduğunda, uyumluluk iyileştirmeleri TestFlight beta sürümleri aracılığıyla kullanıcılarla birlikte geliştirilebilir ve test edilebilir.

Lütfen bu sürecin teknik olabileceğini ve test sırasında aktif iş birliği gerektirebileceğini unutmayın.
