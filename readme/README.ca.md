_**Deixa de lluitar amb interfícies web antiquades.**_

Molts sistemes de control d’accés depenen de pàgines web lentes i difícils d’utilitzar només per obrir una porta o una tanca. GateTap et dona una manera ràpida, moderna i pensada per al tacte de controlar el sistema directament des de l’iPhone.

Creat per a xarxes locals, GateTap es connecta directament al controlador d’accés: sense núvol, sense comptes i sense esperes.

---

## Funcions

• Control de portes i tanques amb un toc  
• Inici de sessió ràpid amb credencials desades (opcional)  
• 🔐 Protecció opcional amb Face ID / Touch ID  
• Funciona íntegrament dins la xarxa local  
• Interfície neta i optimitzada per al tacte  
• No cal connexió al núvol  

---

## Configuració

GateTap està pensat per a usuaris avançats i requereix configuració manual:

1. Introdueix l’adreça IP local del dispositiu  
2. Introdueix les credencials d’inici de sessió  
3. Prova la connexió i comença a controlar el sistema  

GateTap funciona amb sistemes que ofereixen una interfície web integrada. La compatibilitat depèn de la configuració del teu maquinari.

Llegeix la [Guia de configuració](../setup-guide/setup-guide.ca.md) completa.

---

## Privacitat primer

Les teves dades es queden al dispositiu. GateTap no envia credencials ni ordres a servidors externs.

Els informes d’errors (opcionals) es poden desactivar en qualsevol moment.

Llegeix la [Política de privacitat](../legal/ca/privacy-policy.ca.md) i les [Condicions d’ús](../legal/ca/terms-of-use.ca.md) completes.
