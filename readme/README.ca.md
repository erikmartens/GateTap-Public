# GateTap

_**Una interfície moderna d’iPhone per a sistemes de control d’accés compatibles gestionats per web.**_

Un controlador d’accés és un dispositiu que gestiona electrònicament l’obertura de portes, portals, garatges o barreres — per exemple activant un brunzidor de porta a través del sistema d’interfonia o controlant un motor de portal.

Molts sistemes moderns de control d’accés estan connectats a la xarxa local i es poden controlar mitjançant una interfície web. Tanmateix, aquestes interfícies sovint són lentes, difícils i feixugues d’utilitzar. GateTap substitueix les pàgines web antiquades per una experiència ràpida, optimitzada per al tacte i dissenyada per a iPhone.

Creat per a xarxes locals, GateTap es connecta directament als controladors d’accés compatibles — sense serveis al núvol, subscripcions ni comptes externs.

---

## Funcions

• ☑️ Control modern de portals i portes  
• 📱 Interfície intuïtiva i optimitzada per al tacte  
• ⚡ Inici de sessió ràpid amb credencials desades de forma segura o credencials de sessió temporals  
• 🔐 Protecció opcional de l’app amb Face ID / Touch ID  
• 📡 Comunicació directa a la xarxa local  
• ☁️ No cal connexió al núvol  
• 🖥️ Dissenyat per a controladors incrustats gestionats per web  
• 🏢 Compatibilitat amb diversos controladors / diversos llocs  

---

## Compatibilitat

GateTap està dissenyat per a determinats controladors d’accés amb Ethernet o Wi‑Fi que ofereixen una interfície d’administració integrada basada en navegador.

Els sistemes compatibles normalment ofereixen:
- accés local basat en IP
- pàgines d’administració web integrades
- funcionalitat d’inici de sessió al navegador
- control de relés o d’accés a través de la interfície web

La compatibilitat depèn de:
- model del controlador
- versió del microprogramari
- estructura de la interfície web
- configuració de xarxa

### No compatible amb

GateTap generalment **no és compatible** amb:
- sistemes només al núvol
- sistemes només Bluetooth
- comandaments IR independents
- controladors d’accés sense interfícies web
- lectors genèrics sense mòduls de xarxa

## Prova-ho abans de comprar

GateTap es pot baixar i configurar gratuïtament perquè puguis verificar la compatibilitat amb el teu sistema abans de comprar.

La versió gratuïta et permet:
- connectar-te al controlador
- verificar les credencials d’inici de sessió
- provar la compatibilitat
- previsualitzar la interfície del controlador

Una compra única dins de l’app desbloqueja:
- l’activació de portes i portals
- ús operatiu complet del controlador
- compatibilitat amb diversos controladors / diversos llocs
- futures funcions avançades

No cal cap subscripció.

---

## Configuració

GateTap està pensat per a usuaris amb experiència tècnica i requereix configuració manual.

1. Introdueix l’adreça IP local del controlador  
2. Proporciona les teves credencials d’inici de sessió  
3. Prova la connexió  
4. Desbloqueja tota la funcionalitat i comença a controlar el sistema directament des de l’iPhone  

Llegeix la [Guia de configuració](../setup-guide/setup-guide.ca.md) completa.

## Suport i ajuda de compatibilitat

Com que el maquinari de control d’accés varia molt entre fabricants i versions de microprogramari, no es pot garantir la compatibilitat amb tots els sistemes.

Si el teu controlador no és compatible actualment, encara pot ser possible donar-hi suport.

Els usuaris poden contactar amb el suport i proporcionar:
- captures de pantalla de la interfície web del controlador
- pàgines HTML exportades
- informació del model del controlador
- detalls del microprogramari

Quan sigui viable, es poden desenvolupar i provar millores de compatibilitat conjuntament amb els usuaris mitjançant versions beta de TestFlight.

Tingues en compte que aquest procés pot ser tècnic i pot requerir col·laboració activa durant les proves.
