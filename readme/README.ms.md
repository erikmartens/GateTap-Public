# GateTap

_**Antara muka iPhone moden untuk sistem kawalan akses serasi yang diurus melalui web.**_

Pengawal akses ialah peranti yang mengurus pembukaan pintu, pagar, garaj atau palang secara elektronik — contohnya dengan mengaktifkan pembuka pintu melalui sistem interkom anda atau mengawal motor pagar.

Banyak sistem kawalan akses moden disambungkan ke rangkaian tempatan dan boleh dikawal melalui antara muka web. Namun, antara muka ini sering perlahan, sukar dan menyusahkan untuk digunakan. GateTap menggantikan laman web lama dengan pengalaman pantas yang dioptimumkan untuk sentuhan dan direka untuk iPhone.

Dibina untuk rangkaian tempatan, GateTap bersambung terus kepada pengawal akses yang serasi — tanpa perkhidmatan awan, langganan atau akaun luaran.

---

## Ciri

• ☑️ Kawalan pagar & pintu moden  
• 📱 Antara muka intuitif yang dioptimumkan untuk sentuhan  
• ⚡ Log masuk pantas dengan kelayakan yang disimpan dengan selamat atau kelayakan sesi sementara  
• 🔐 Perlindungan aplikasi pilihan melalui Face ID / Touch ID  
• 📡 Komunikasi rangkaian tempatan langsung  
• ☁️ Tiada sambungan awan diperlukan  
• 🖥️ Direka untuk pengawal terbenam yang diurus melalui web  
• 🏢 Sokongan berbilang pengawal / berbilang lokasi  

---

## Keserasian

GateTap direka untuk pengawal akses tertentu yang menyokong Ethernet atau Wi‑Fi dan menyediakan antara muka pengurusan terbina dalam berasaskan pelayar.

Sistem yang serasi biasanya menyediakan:
- akses tempatan berasaskan IP
- halaman pentadbiran web terbina dalam
- fungsi log masuk pelayar
- kawalan geganti atau akses melalui antara muka web

Keserasian bergantung pada:
- model pengawal
- versi perisian tegar
- struktur antara muka web
- konfigurasi rangkaian

### Tidak serasi dengan

GateTap secara umum **tidak serasi** dengan:
- sistem awan sahaja
- sistem Bluetooth sahaja
- alat kawalan jauh IR kendiri
- pengawal akses tanpa antara muka web
- pembaca generik tanpa modul rangkaian

---

## Cuba sebelum membeli

GateTap boleh dimuat turun dan dikonfigurasi secara percuma supaya anda boleh mengesahkan keserasian dengan sistem anda sebelum membeli.

Versi percuma membolehkan anda:
- bersambung ke pengawal anda
- mengesahkan kelayakan log masuk
- menguji keserasian
- pratonton antara muka pengawal

Pembelian dalam aplikasi sekali sahaja membuka:
- pencetus pagar & pintu
- penggunaan operasi penuh pengawal
- sokongan berbilang pengawal / berbilang lokasi
- ciri lanjutan masa hadapan

Tiada langganan diperlukan.

---

## Persediaan

GateTap ditujukan kepada pengguna yang berpengalaman secara teknikal dan memerlukan konfigurasi manual.

1. Masukkan alamat IP tempatan pengawal anda  
2. Berikan kelayakan log masuk anda  
3. Uji sambungan  
4. Buka fungsi penuh dan mula mengawal sistem anda terus daripada iPhone  

Baca [Panduan Persediaan](../setup-guide/setup-guide.ms.md) penuh.

## Sokongan & Bantuan Keserasian

Oleh sebab perkakasan kawalan akses berbeza dengan ketara antara pengeluar dan versi perisian tegar, keserasian tidak boleh dijamin untuk semua sistem.

Jika pengawal anda tidak disokong pada masa ini, sokongan mungkin masih boleh dilakukan.

Pengguna boleh menghubungi sokongan dan menyediakan:
- tangkapan skrin antara muka web pengawal
- halaman HTML yang dieksport
- maklumat model pengawal
- butiran perisian tegar

Jika boleh dilaksanakan, penambahbaikan keserasian boleh dibangunkan dan diuji bersama pengguna melalui binaan beta TestFlight.

Sila ambil perhatian bahawa proses ini boleh menjadi teknikal dan mungkin memerlukan kerjasama aktif semasa ujian.
