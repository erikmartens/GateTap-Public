_**Hentikan kesukaran menggunakan antara muka web lama.**_

Banyak sistem kawalan akses bergantung pada halaman pelayar yang perlahan dan sukar digunakan hanya untuk membuka pintu atau pagar. GateTap memberi anda cara yang pantas, moden dan mesra sentuhan untuk mengawal sistem terus daripada iPhone.

Dibina untuk rangkaian tempatan, GateTap bersambung terus ke pengawal akses anda — tanpa awan, tanpa akaun, tanpa lengah.

---

## Ciri

• Kawalan pintu dan pagar dengan satu ketikan  
• Log masuk pantas dengan kelayakan tersimpan (pilihan)  
• 🔐 Perlindungan pilihan dengan Face ID / Touch ID  
• Berfungsi sepenuhnya dalam rangkaian tempatan anda  
• Antara muka bersih dan dioptimumkan untuk sentuhan  
• Tidak memerlukan sambungan awan  

---

## Persediaan

GateTap direka untuk pengguna lanjutan dan memerlukan persediaan manual:

1. Masukkan alamat IP tempatan peranti  
2. Berikan kelayakan log masuk anda  
3. Uji sambungan dan mula mengawal sistem  

GateTap berfungsi dengan sistem yang menyediakan antara muka web terbina dalam. Keserasian bergantung pada konfigurasi perkakasan anda.

Baca [Panduan Persediaan](../setup-guide/setup-guide.ms.md) penuh.

---

## Privasi diutamakan

Data anda kekal pada peranti anda. GateTap tidak menghantar kelayakan atau arahan anda ke pelayan luaran.

Laporan ranap pilihan boleh dinyahaktifkan pada bila-bila masa.

Baca [Dasar Privasi](../legal/ms/privacy-policy.ms.md) dan [Terma Penggunaan](../legal/ms/terms-of-use.ms.md) penuh.
