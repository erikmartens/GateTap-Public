_**Nu te mai lupta cu interfețe web învechite.**_

Multe sisteme de control al accesului se bazează pe pagini web lente și greu de folosit doar pentru a deschide o ușă sau o poartă. GateTap îți oferă o modalitate rapidă, modernă și optimizată pentru atingere de a controla sistemul direct de pe iPhone.

Construit pentru rețele locale, GateTap se conectează direct la controlerul tău de acces — fără cloud, fără conturi, fără întârzieri.

---

## Funcții

• Control pentru uși și porți cu o singură atingere  
• Autentificare rapidă cu date salvate (opțional)  
• 🔐 Protecție opțională cu Face ID / Touch ID  
• Funcționează integral în rețeaua ta locală  
• Interfață curată, optimizată pentru atingere  
• Nu necesită conexiune cloud  

---

## Configurare

GateTap este conceput pentru utilizatori avansați și necesită configurare manuală:

1. Introdu adresa IP locală a dispozitivului  
2. Furnizează datele de autentificare  
3. Testează conexiunea și începe să controlezi sistemul  

GateTap funcționează cu sisteme care oferă o interfață web integrată. Compatibilitatea depinde de configurația hardware.

Citește [Ghidul de configurare](../setup-guide/setup-guide.ro.md) complet.

---

## Confidențialitatea pe primul loc

Datele tale rămân pe dispozitiv. GateTap nu trimite datele de autentificare sau comenzile către servere externe.

Raportarea opțională a erorilor poate fi dezactivată oricând.

Citește [Politica de confidențialitate](../legal/ro/privacy-policy.ro.md) și [Termenii de utilizare](../legal/ro/terms-of-use.ro.md) compleți.
