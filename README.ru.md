_**Мгновенное управление дверями и воротами**_

GateTap позволяет управлять совместимыми локальными контроллерами доступа с iPhone в вашей собственной сети.

Приложение подключается напрямую к контроллеру. Облачная учетная запись для команд не требуется.

---

## Возможности

- Открывайте двери и ворота на вкладке Access.
- Сохраняйте адрес контроллера и при необходимости учетные данные локально.
- Используйте временные учетные данные только для текущего сеанса.
- Защищайте приложение с помощью Face ID, Touch ID или кода устройства.
- Читайте руководство, политику конфиденциальности и условия из того же источника, что и приложение.
