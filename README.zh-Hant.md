_**即時門禁與大門控制**_

GateTap 可讓你在自己的本機網路中，透過 iPhone 控制相容的本機門禁控制器。

App 會直接連線到控制器。傳送門和大門控制指令不需要雲端帳號。

---

## 功能

- 從「Access」分頁開啟門和大門。
- 在本機儲存控制器位址，並可選擇儲存登入憑證。
- 僅在目前 App 工作階段使用臨時憑證。
- 使用 Face ID、Touch ID 或裝置密碼保護 App。
- 從與 App 相同的來源閱讀設定、隱私權和條款文件。
