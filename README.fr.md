_**Contrôle instantané des portes et portails**_

GateTap vous permet de contrôler des contrôleurs d’accès locaux compatibles depuis votre iPhone lorsque vous êtes sur votre réseau.

L’app se connecte directement au contrôleur. Aucun compte cloud n’est nécessaire pour envoyer des commandes.

---

## Fonctionnalités

- Ouvrez portes et portails depuis l’onglet Accès.
- Enregistrez l’adresse du contrôleur et, si vous le souhaitez, les identifiants localement.
- Utilisez des identifiants temporaires pour la session en cours.
- Protégez l’app avec Face ID, Touch ID ou le code de l’appareil.
- Consultez la configuration, la confidentialité et les conditions depuis la même source que l’app.
