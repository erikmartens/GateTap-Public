_**تحكم فوري بالأبواب والبوابات**_

يتيح لك GateTap التحكم بوحدات التحكم المحلية المتوافقة من iPhone عندما تكون داخل شبكتك الخاصة.

يتصل التطبيق مباشرة بوحدة التحكم. لا يلزم حساب سحابي لأوامر الأبواب والبوابات.

---

## الميزات

- افتح الأبواب والبوابات من تبويب الوصول.
- احفظ عنوان وحدة التحكم وبيانات الدخول محليًا عند الحاجة.
- استخدم بيانات دخول مؤقتة لجلسة التطبيق الحالية فقط.
- احمِ التطبيق باستخدام Face ID أو Touch ID أو رمز الجهاز.
- اقرأ دليل الإعداد والخصوصية والشروط من نفس المصدر المستخدم في التطبيق.
