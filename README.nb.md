_**Umiddelbar kontroll av dører og porter**_

GateTap lar deg styre kompatible lokale adgangskontrollere fra iPhone mens du er på ditt eget nettverk.

Appen kobler direkte til kontrolleren. Ingen skykonto kreves for dør- og portkommandoer.

---

## Funksjoner

- Åpne dører og porter fra Tilgang-fanen.
- Lagre kontrolleradresse og eventuelt innloggingsdata lokalt.
- Bruk midlertidige innloggingsdata for gjeldende appøkt.
- Beskytt appen med Face ID, Touch ID eller enhetskode.
- Les oppsett, personvern og vilkår fra samme kilde som appen.
