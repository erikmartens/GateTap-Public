_**Control instant pentru uși și porți**_

GateTap îți permite să controlezi controlere locale compatibile de pe iPhone atunci când ești în propria rețea.

Aplicația se conectează direct la controler. Nu este necesar un cont cloud pentru comenzi.

---

## Funcții

- Deschide uși și porți din fila Acces.
- Salvează local adresa controlerului și, opțional, datele de autentificare.
- Folosește date temporare pentru sesiunea curentă.
- Protejează aplicația cu Face ID, Touch ID sau codul dispozitivului.
- Citește ghidul, confidențialitatea și termenii din aceeași sursă ca aplicația.
