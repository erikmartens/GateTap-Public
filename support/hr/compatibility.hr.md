> GateTap je neovisan projekt i nije povezan s proizvođačima hardvera za kontrolu pristupa.
>
> Kompatibilnost može varirati ovisno o:
> - verziji firmvera
> - reviziji hardvera
> - verziji web sučelja
> - mrežnoj konfiguraciji

Kontroleri koji nisu navedeni ovdje i dalje mogu raditi ako pružaju kompatibilno web sučelje temeljeno na pregledniku.

# Poznati kompatibilni sustavi

|---|---|---|
| Webserver Wiegand 4 Door Access Controller Board DH-7004 | V6.62.51215 | ✅ Potpuno radi |

---

# Napomene

Testirani kontroler čini se kompatibilnim ili blisko povezanim sa sustavima koji se prodaju pod nazivima kao što su:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- slični generički Wiegand Ethernet kontroleri pristupa

Budući da se mnogi od tih sustava prodaju pod različitim markama, kompatibilnost se može proširiti na slične hardverske varijante koje koriste isto web sučelje.

---

# Izvješća zajednice

Dodatni sustavi koje je testirala zajednica mogu biti dodani u budućnosti.

Za prijavu kompatibilnosti uključite:
- model kontrolera
- verziju firmvera
- snimke zaslona web sučelja
- izvezene HTML stranice ako je moguće
