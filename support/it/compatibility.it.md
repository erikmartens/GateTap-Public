> GateTap è un progetto indipendente e non è affiliato a produttori di hardware per il controllo accessi.
>
> La compatibilità può variare in base a:
> - versione del firmware
> - revisione hardware
> - versione dell’interfaccia web
> - configurazione di rete

I controller non elencati qui possono comunque funzionare se forniscono un’interfaccia web compatibile basata su browser.

---

# Note

Il controller testato sembra essere compatibile o strettamente correlato a sistemi venduti con nomi come:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- controller di accesso Wiegand Ethernet generici simili

Poiché molti di questi sistemi vengono rimarchiati, la compatibilità può estendersi a varianti hardware simili che utilizzano la stessa interfaccia web.

# Segnalazioni della community

In futuro potranno essere aggiunti altri sistemi testati dalla community.

Per segnalare la compatibilità, includi:
- modello del controller
- versione del firmware
- schermate dell’interfaccia web
- pagine HTML esportate se possibile
