> GateTap är ett oberoende projekt och är inte kopplat till tillverkare av passerkontrollhårdvara.
>
> Kompatibilitet kan variera beroende på:
> - firmwareversion
> - hårdvarurevision
> - webbgränssnittsversion
> - nätverkskonfiguration

Kontroller som inte listas här kan ändå fungera om de tillhandahåller ett kompatibelt webbläsarbaserat webbgränssnitt.

# Anteckningar

Den testade kontrollern verkar vara kompatibel med eller nära besläktad med system som säljs under namn som:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- liknande generiska Wiegand Ethernet-passerkontroller

Eftersom många av dessa system säljs under andra märken kan kompatibiliteten omfatta liknande hårdvaruvarianter som använder samma webbgränssnitt.

---

# Communityrapporter

Ytterligare system som testats av communityn kan läggas till i framtiden.

För att rapportera kompatibilitet, inkludera:
- kontrollermodell
- firmwareversion
- skärmbilder av webbgränssnittet
- exporterade HTML-sidor om möjligt
