> GateTap 是独立项目，与门禁硬件制造商没有关联。
>
> 兼容性可能因以下因素而异：
> - 固件版本
> - 硬件修订版本
> - Web 界面版本
> - 网络配置

未在此列出的控制器如果提供兼容的浏览器式 Web 界面，仍可能可以工作。

|---|---|---|
| Webserver Wiegand 4 Door Access Controller Board DH-7004 | V6.62.51215 | ✅ 完全可用 |

---

# 说明

经测试的控制器似乎与以下名称销售的系统兼容或关系密切：
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- 类似的通用 Wiegand Ethernet 门禁控制器

由于许多此类系统会以不同品牌重新销售，兼容性可能扩展到使用相同 Web 界面的类似硬件变体。
