> GateTap est un projet indépendant et n’est affilié à aucun fabricant de matériel de contrôle d’accès.
>
> La compatibilité peut varier selon:
> - version du firmware
> - révision matérielle
> - version de l’interface web
> - configuration réseau

Les contrôleurs non listés ici peuvent tout de même fonctionner s’ils fournissent une interface web compatible basée sur navigateur.

# Notes

Le contrôleur testé semble compatible ou étroitement lié à des systèmes vendus sous des noms tels que:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- contrôleurs d’accès Wiegand Ethernet génériques similaires

Comme beaucoup de ces systèmes sont revendus sous différentes marques, la compatibilité peut s’étendre à des variantes matérielles similaires utilisant la même interface web.

# Rapports de la communauté

D’autres systèmes testés par la communauté pourront être ajoutés à l’avenir.

Pour signaler une compatibilité, veuillez inclure:
- modèle du contrôleur
- version du firmware
- captures d’écran de l’interface web
- pages HTML exportées si possible
