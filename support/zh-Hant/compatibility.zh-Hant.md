# 說明

經測試的控制器似乎與以下名稱銷售的系統相容或關係密切：
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- 類似的一般 Wiegand Ethernet 門禁控制器

由於許多此類系統會以不同品牌重新銷售，相容性可能延伸至使用相同 Web 介面的類似硬體變體。
