> GateTap este un proiect independent și nu este afiliat producătorilor de hardware pentru controlul accesului.
>
> Compatibilitatea poate varia în funcție de:
> - versiunea firmware
> - revizia hardware
> - versiunea interfeței web
> - configurarea rețelei

Controlerele care nu sunt listate aici pot funcționa totuși dacă oferă o interfață web compatibilă bazată pe browser.

# Sisteme compatibile cunoscute

## Verificat de dezvoltator

| Controler | Versiune firmware / driver | Rezultat |
|---|---|---|
| Webserver Wiegand 4 Door Access Controller Board DH-7004 | V6.62.51215 | ✅ Complet funcțional |

---

# Note

Controlerul testat pare să fie compatibil sau strâns înrudit cu sisteme vândute sub nume precum:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- controlere de acces Wiegand Ethernet generice similare

Deoarece multe dintre aceste sisteme sunt rebranduite, compatibilitatea se poate extinde la variante hardware similare care folosesc aceeași interfață web.
