> O GateTap é um projeto independente e não é afiliado a fabricantes de hardware de controlo de acesso.
>
> A compatibilidade pode variar consoante:
> - versão do firmware
> - revisão do hardware
> - versão da interface web
> - configuração da rede

Controladores não listados aqui ainda podem funcionar se disponibilizarem uma interface web compatível baseada no navegador.

# Notas

O controlador testado parece ser compatível ou estar estreitamente relacionado com sistemas vendidos sob nomes como:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- controladores de acesso Wiegand Ethernet genéricos semelhantes

Como muitos destes sistemas são revendidos com outras marcas, a compatibilidade pode estender-se a variantes de hardware semelhantes que utilizam a mesma interface web.
