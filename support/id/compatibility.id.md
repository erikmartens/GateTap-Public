> GateTap adalah proyek independen dan tidak berafiliasi dengan produsen perangkat keras kontrol akses.
>
> Kompatibilitas dapat bervariasi tergantung pada:
> - versi firmware
> - revisi perangkat keras
> - versi antarmuka web
> - konfigurasi jaringan

Kontroler yang tidak tercantum di sini mungkin tetap berfungsi jika menyediakan antarmuka web berbasis browser yang kompatibel.

---

# Sistem kompatibel yang diketahui

## Diverifikasi oleh pengembang

| Kontroler | Versi firmware / driver | Hasil |
|---|---|---|
| Webserver Wiegand 4 Door Access Controller Board DH-7004 | V6.62.51215 | ✅ Berfungsi penuh |

---

# Catatan

Kontroler yang diuji tampaknya kompatibel atau berkerabat dekat dengan sistem yang dijual dengan nama seperti:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- kontroler akses Wiegand Ethernet generik serupa

Karena banyak sistem ini dijual ulang dengan merek berbeda, kompatibilitas dapat meluas ke varian perangkat keras serupa yang menggunakan antarmuka web yang sama.

---

# Laporan komunitas

Sistem tambahan yang diuji komunitas dapat ditambahkan di masa mendatang.

Untuk melaporkan kompatibilitas, harap sertakan:
- model kontroler
- versi firmware
- tangkapan layar antarmuka web
- halaman HTML yang diekspor jika memungkinkan

# Penafian

Kompatibilitas dapat berubah setelah pembaruan firmware atau revisi perangkat keras.
