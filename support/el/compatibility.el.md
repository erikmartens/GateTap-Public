> Το GateTap είναι ένα ανεξάρτητο έργο και δεν συνδέεται με κατασκευαστές υλικού ελέγχου πρόσβασης.
>
> Η συμβατότητα μπορεί να διαφέρει ανάλογα με:
> - έκδοση firmware
> - αναθεώρηση υλικού
> - έκδοση διεπαφής web
> - διαμόρφωση δικτύου

Ελεγκτές που δεν αναφέρονται εδώ μπορεί να λειτουργούν ακόμη, εφόσον παρέχουν συμβατή διεπαφή web βασισμένη σε πρόγραμμα περιήγησης.

# Σημειώσεις

Ο ελεγμένος ελεγκτής φαίνεται να είναι συμβατός ή στενά σχετικός με συστήματα που πωλούνται με ονόματα όπως:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- παρόμοιοι γενικοί ελεγκτές πρόσβασης Wiegand Ethernet

Επειδή πολλά από αυτά τα συστήματα επανακυκλοφορούν με διαφορετικές μάρκες, η συμβατότητα μπορεί να επεκτείνεται σε παρόμοιες παραλλαγές υλικού που χρησιμοποιούν την ίδια διεπαφή web.

# Αναφορές κοινότητας

Πρόσθετα συστήματα που έχουν δοκιμαστεί από την κοινότητα μπορεί να προστεθούν στο μέλλον.

Για αναφορά συμβατότητας, παρακαλούμε συμπεριλάβετε:
- μοντέλο ελεγκτή
- έκδοση firmware
- στιγμιότυπα οθόνης της διεπαφής web
- εξαγόμενες σελίδες HTML αν είναι δυνατό
