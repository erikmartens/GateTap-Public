> GateTap es un proyecto independiente y no está afiliado a fabricantes de hardware de control de acceso.
>
> La compatibilidad puede variar según:
> - versión del firmware
> - revisión del hardware
> - versión de la interfaz web
> - configuración de red

Los controladores que no aparecen aquí pueden funcionar igualmente si ofrecen una interfaz web compatible basada en navegador.

# Notas

El controlador probado parece ser compatible o estar estrechamente relacionado con sistemas vendidos con nombres como:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- controladores de acceso Wiegand Ethernet genéricos similares

Como muchos de estos sistemas se venden con otras marcas, la compatibilidad puede extenderse a variantes de hardware similares que utilicen la misma interfaz web.

# Reportes de la comunidad

Es posible que se agreguen en el futuro otros sistemas probados por la comunidad.

Para reportar compatibilidad, incluye:
- modelo del controlador
- versión del firmware
- capturas de pantalla de la interfaz web
- páginas HTML exportadas si es posible
