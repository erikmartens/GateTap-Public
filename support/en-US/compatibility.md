# Notes

The tested controller appears to be compatible or closely related to systems sold under names such as:
- Webserver Wiegand 4 Door Access Controller Board DH-7004
- S4A Network Four Door Wiegand Access Controller Panel
- similar generic Wiegand Ethernet access controllers

Because many of these systems are rebranded, compatibility may extend to similar hardware variants using the same web interface.

# Community Reports

- firmware version
- screenshots of the web interface
- exported HTML pages if possible
