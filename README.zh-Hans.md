_**即时门禁与大门控制**_

GateTap 可让你在自己的本地网络中，通过 iPhone 控制兼容的本地门禁控制器。

App 会直接连接到控制器。发送门和大门控制指令不需要云账户。

---

## 功能

- 从“Access”标签打开门和大门。
- 在本地保存控制器地址，并可选择保存登录凭据。
- 仅在当前 App 会话中使用临时凭据。
- 使用 Face ID、Touch ID 或设备密码保护 App。
- 从与 App 相同的来源阅读设置、隐私和条款文档。
