_**즉시 문과 게이트 제어**_

GateTap은 사용자의 네트워크 안에서 호환되는 로컬 출입 제어기를 iPhone으로 제어할 수 있게 해줍니다.

앱은 제어기에 직접 연결됩니다. 문과 게이트 명령에 클라우드 계정이 필요하지 않습니다.

---

## 기능

- Access 탭에서 문과 게이트를 엽니다.
- 제어기 주소와 선택적으로 자격 증명을 로컬에 저장합니다.
- 현재 앱 세션에만 임시 자격 증명을 사용합니다.
- Face ID, Touch ID 또는 기기 암호로 앱을 보호합니다.
- 앱과 같은 출처의 설정, 개인정보 보호 및 이용 약관 문서를 확인합니다.
