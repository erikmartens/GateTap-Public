_**ドアとゲートをすばやく制御**_

GateTap は、自分のネットワーク内で互換性のあるローカルアクセスコントローラを iPhone から制御できます。

アプリはコントローラに直接接続します。ドアやゲートの操作にクラウドアカウントは不要です。

---

## 機能

- Access タブからドアやゲートを開けられます。
- コントローラのアドレスと必要に応じて認証情報をローカルに保存できます。
- 現在のアプリセッションだけで一時認証情報を使用できます。
- Face ID、Touch ID、またはデバイスのパスコードでアプリを保護できます。
- セットアップ、プライバシー、利用規約をアプリと同じソースから確認できます。
