_**Controllo immediato di porte e cancelli**_

GateTap ti consente di controllare controller di accesso locali compatibili dall'iPhone mentre sei nella tua rete.

L'app si collega direttamente al controller. Non serve un account cloud per inviare comandi.

---

## Funzioni

- Apri porte e cancelli dalla scheda Accesso.
- Salva localmente l'indirizzo del controller e, se vuoi, le credenziali.
- Usa credenziali temporanee per la sessione corrente.
- Proteggi l'app con Face ID, Touch ID o codice del dispositivo.
- Leggi configurazione, privacy e termini dalla stessa fonte usata dall'app.
