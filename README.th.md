_**ควบคุมประตูและประตูรั้วได้ทันที**_

GateTap ช่วยให้คุณควบคุมตัวควบคุมการเข้าถึงภายในเครื่องที่เข้ากันได้จาก iPhone เมื่ออยู่ในเครือข่ายของคุณเอง

แอปเชื่อมต่อกับตัวควบคุมโดยตรง ไม่จำเป็นต้องมีบัญชีคลาวด์สำหรับคำสั่งประตูและประตูรั้ว

---

## คุณสมบัติ

- เปิดประตูและประตูรั้วจากแท็บ Access
- บันทึกที่อยู่ตัวควบคุมและเลือกบันทึกข้อมูลเข้าสู่ระบบไว้ในเครื่อง
- ใช้ข้อมูลเข้าสู่ระบบชั่วคราวสำหรับเซสชันแอปปัจจุบัน
- ปกป้องแอปด้วย Face ID, Touch ID หรือรหัสอุปกรณ์
- อ่านคู่มือ ความเป็นส่วนตัว และข้อกำหนดจากแหล่งเดียวกับที่แอปใช้

---

ใช้คู่มือการตั้งค่าเพื่อค้นหาตัวควบคุม เข้าสู่ระบบ และเชื่อมต่อ GateTap
