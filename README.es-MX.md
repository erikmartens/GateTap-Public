_**Control instantáneo de puertas y portones**_

GateTap te permite controlar controladores de acceso locales compatibles desde tu iPhone dentro de tu propia red.

La app se conecta directamente al controlador. No se necesita una cuenta en la nube para enviar comandos.

---

## Funciones

- Abre puertas y portones desde la pestaña Acceso.
- Guarda la dirección del controlador y opcionalmente las credenciales de forma local.
- Usa credenciales temporales durante la sesión actual.
- Protege la app con Face ID, Touch ID o el código del dispositivo.
- Consulta la guía, privacidad y términos desde la misma fuente que usa la app.
