## 1. Ikhtisar
GateTap menghormati privasi Anda. Aplikasi ini dirancang untuk beroperasi terutama pada perangkat Anda dan dalam jaringan lokal Anda.

## 2. Pengumpulan Data
GateTap tidak mengumpulkan, menyimpan, atau mengirimkan data pribadi ke server eksternal untuk penggunaan fungsional Aplikasi.

Aplikasi dapat menyimpan informasi berikut secara lokal di perangkat Anda:
- Alamat IP perangkat yang dikonfigurasi
- Kredensial login (opsional, jika Anda memilih untuk menyimpannya)

Data ini tidak pernah meninggalkan perangkat Anda.

## 3. Pelaporan Kerusakan (Opsional)
GateTap menggunakan layanan pihak ketiga yang disediakan oleh Google Firebase Crashlytics untuk mengumpulkan laporan kerusakan anonim guna meningkatkan stabilitas aplikasi.

Laporan kerusakan mungkin mencakup:
- Jenis perangkat dan versi sistem operasi
- Versi aplikasi
- Informasi teknis tentang kecelakaan itu

Tidak ada data pribadi atau kredensial yang disertakan dalam laporan kerusakan.

Anda dapat menonaktifkan pelaporan kerusakan kapan saja di pengaturan aplikasi.

## 4. Komunikasi Jaringan
GateTap berkomunikasi langsung dengan perangkat yang dikonfigurasi melalui jaringan lokal Anda. Tidak ada data perintah atau kredensial yang dirutekan melalui server eksternal.

## 5. Tidak Ada Pelacakan
GateTap tidak menggunakan teknologi pelacakan, pengidentifikasi iklan, atau pembuatan profil.

## 6. Keamanan
Semua data sensitif tetap ada di perangkat Anda. Anda bertanggung jawab untuk mengamankan perangkat Anda menggunakan perlindungan tingkat sistem (misalnya, kode sandi, ID Wajah).

## 7. Sistem Pihak Ketiga
GateTap berinteraksi dengan sistem perangkat keras pihak ketiga. Keamanan dan perilaku sistem tersebut berada di luar kendali Aplikasi.

## 8. Perubahan
Kebijakan Privasi ini mungkin diperbarui di masa mendatang. Perubahan akan terlihat di Aplikasi.
